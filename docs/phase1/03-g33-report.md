## 方法上の差異の申告(同一手法再現における既知の差)

1. 積分器: BJ は rk78f 1000 步、本機構はリープフロッグ 2000 步+放物線精密化
   (GJ710 で刻み幅収束確認済み)
2. mock 完全側: BJ は Galaxia 直サンプル、本機構は同一モデル系 (GDR2mock) の
   局所体積からの解析的 a 再構築
3. C マップのビン幅は BJ 論文に非公開 → 本機構は Δt=1 Myr × Δd=0.5 pc を既定とし
   感度確認を添える
4. 位置誤差 (ra/dec) はサロゲートに含む(5×5)が、寄与は ~10⁻⁵ pc
