## 3. 原因究明(機構側の検証 — 完了)

1. **LMA 閉形式**(独立算術): DR3 入力 (d=19.09 pc, μ=0.428 mas/yr, v_r=−14.42)
   から機械的に t=1.2943 Myr / d=0.0513 pc。手計算で検算可能:
   d_ph ≈ d·v_T/v = 19.09 × (4.74047×10⁻³×0.428×19.09)/14.42 = 0.0513 pc
2. **数値積分の刻み幅収束**: dt = 0.002 → 0.0005 → 0.0002 Myr で
   DC95: 0.0503 pc、MW2014: 0.0519 pc に収束(放物線精密化バイアス +0.0004 を確認・除去)
3. **独立実装との突き合わせ(G2)**: コード非共有のエピサイクル解析経路が
   t=1.2946 / d=0.0521 — 数値経路 (MW2014) と 0.2 mpc で一致
4. **公刊側の独立検算との一致**: dlFM22(Aarseth N体+DE440/441)= 0.052、
   BB22(軸対称+渦状波ポテンシャル積分)= 0.052

→ 4手法(算術・積分2種・独立解析)+公刊2系が 0.050–0.052 で相互一致。
**機構側に実装バグの証拠はない。**

## 4. 公刊側の状況(事実)

- **0.051–0.052 陣営**: dlFM22 (DR3+N体)、BB22 (DR3+積分, d のみ)、本機構
- **0.062–0.068 陣営**: Berski & Dybczyński 2016 (DR1)、BJ+18 (DR2)、
  BJ22 (DR3)、FP26 (DR3+RV補正)
- BJ22/FP26 の d_ph は、**彼ら自身が記載した入力から LMA 算術でも導出できない**
  (入力からは 0.051 系が出る。軌道曲率の寄与は本検証で ≤0.002 pc と実測)
- 旧解釈「採用 RV の差 (−14.5 vs −13.9) による分裂」は転記により**棄却**
  (BJ22 は −14.4 を採用して 0.0636、BB22 は −14.42 で 0.052)
- BB22 の t=1.324 も同入力の LMA (1.294)・dlFM22 (1.29)・BJ22 (1.292) と乖離
  (BB22 のみの孤立値。同論文の線形法の行も t=1.325/d=0.051 と d は一致・t は乖離)
