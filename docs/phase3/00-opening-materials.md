## 付議1 — マーク場 (c) パラメータ写像(裁定ログ#9 予約の履行)

### 対応表(定理 C2/D ↔ CN19 境界条件)

| 接触過程 M(ρ,ν,R,p,τ,T_s) | CN19 境界条件 (f, v_p, d_p, T_s) | 写像 |
|---|---|---|
| R(到達半径) | d_p(探査機航続距離) | **R = d_p**(直接) |
| τ(遅延) | v_p(探査機速度) | **τ = d_p / v_p**(進入駆動: 進入時発進・航続距離級の旅行時間) |
| p(成功確率) | 定住可能割合×成功率 | **p = f_set**(CN19 の settleable fraction 系) |
| T_s(寿命) | T_s(定住系の寿命) | 直接 |
| ρ, ν(運動学) | — | **実測固定**(Phase 2 カタログ — 自由パラメータではない) |
| f(入植済み割合) | f | マーク場の規格化(境界条件層から供給) |

### 許容域の評価規約(裁定ログ#12 指定事項)

- 臨界条件: **p·λ(R)·T_s ≳ O(1)**(定理A+C2 の挟み込み。定数は非最適 —
  数値閾値 m ≈ 1.0–1.3(E1)を許容域の中心、定理は存在保証)
- **λ の選択(案)**: クリーン母集団の実測 λ を主、suspect 込みを両建て併記
  (憲法第7条3項)。K_mix = w̄T_s/R ≥ 20 の混合条件も同時に判定
  (実測 w̄ ≈ 25 km/s 級 → T_s ≳ 0.8 Myr·(R/pc) で充足 — ほぼ常に成立)
- **距離スケール規約(案)**: λ(R) は実測アンカー λ@{1,2,5}pc
  (4.49 / 27.5 / 137.3)の**区分冪補間**で評価(実測スケーリング 6.1×/5.0× —
  厳密 d² からの偏差込み、裁定#12 注記)。R < 1 pc は d² 外挿+
  「外挿域」フラグ、R > 5 pc は判定不能(カタログ支持域外)
- (c) クラスター族の許容域への含意: Phase 2 実測で λ(t) に相関クラスターなし
  (08-clump-analysis)→ (c) 族は「クラスターなし近傍」が実測整合域。
  逆向きチャネル注記(裁定ログ#9 必須)は再入植項の平均場補正として地図脚注へ
