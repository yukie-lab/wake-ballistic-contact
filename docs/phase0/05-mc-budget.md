「1回の測定を信じない」どおり、定常値 38.5 ns/星/ステップ側を採用。

### 1.3 プロセス並列(実現方向、N=100,000・dt=0.05・±10 Myr)

交互2回測定(測定汚染対策):

| workers | 実現/秒 |
|---|---|
| 6 | 1.31 / 1.33 |
| 8 | 1.23 / 1.21 |

**workers=6 確定、1.33 実現/秒。** 8 は劣化 — 憲法第2条4項の実測則が本ワークロードでも再現。
並列効率は 2.7 倍止まり(単一 0.50 実現/秒 → 1.33)。numpy がすでにメモリ帯域を
飽和させるため、warpax(Python トレーシング律速で 4.7 倍)より伸びない。これは織り込む。

## 2. 一晩(8時間)の被覆見積

| 構成 | 1実現 | 一晩の実現数 |
|---|---|---|
| N=1e5, dt=0.05(標準) | 0.75 s | **約 38,000** |
| N=1e5, dt=0.01(精密) | ~3.8 s | 約 7,600 |
| N=1e6, dt=0.05(全RVSカタログ級) | ~10 s(並列) | 約 2,900 |

結論: **誤差 MC 1,000〜10,000 実現は標準構成なら数時間で完了。** 計算予算は本プロジェクトの
制約にならない。排除地図のパラメータ格子 (f, v, R, L) は接近イベントアンサンブルを
再利用して塗るため伝播の再計算は不要 — 格子側のコストはさらに軽い。

## 3. 誤差 MC 設計(ドラフト)

1. **サンプリング単位**: 1実現 = 全星の 6D を誤差からリサンプル → 伝播 → 接近イベント抽出。
   実現間は独立、実現内で全星同時(共分散はステップ間で保存)。
2. **全共分散 vs 対角近似**: スキーマ v0 は 5×5 アストロメトリ相関(上三角10個)を保持済み。
   コストは対角とほぼ同オーダー(リサンプルは伝播に比べ軽い)ので**全共分散を既定**とし、
   対角近似は感度チェック用に残す。Bailer-Jones 系の標準(サロゲートサンプリング)と揃える。
3. **乱数規律**: 実現番号 = シード。全実現が決定論的に再現可能(第11条・再現性要件の先取り)。
4. **接近検出**: 軌道は保存せず、ステップごとに min 距離を更新(メモリ O(N))。
   最接近近傍は局所補間(3点放物線)で精密化 — Phase 1 で実装。
5. **積分刻みの当面値**: dt=0.05 Myr を標準、G3 アンカー検証時に dt=0.01 との差分で収束確認。
   最終値は Phase 1 冒頭の個別ホライズン裁定と合わせて固定する。
