### 無次元化(スケール t_p ≡ d_p/v_p)と導出量

- η = fρd_p³(太陽近傍で η = 2.3 f (d_p/10 lyr)³)、範囲 [0.1, 10]
- ν_s = v_s/v_p ∈ [10⁻³, 10⁻¹]、τ_p = T_p/t_p ∈ [0.1, 1]
- **T_c = (π f ρ d_p² v_s)⁻¹**: 遭遇律速時間 — **本プロジェクトが実カタログで直接計算し直す中核量**
- D₁ = 1 − exp(−(4π/3)εη)(ε = 1/4 は前線計算のみ)、T_l = D₁T_p + (1−D₁)T_c
- 前線速度 ν = max[𝒱ν_s, ν_l](𝒱 = 2–3.5: N 個中最速星の速度比)、前線厚み Δξ = ντ_l/ln2
- 接続性遷移: η₁≈0.1700, η₂≈0.4030, η₃≈0.6399, η₄≈0.8777(η > η₄ でほぼ完全連結)
- 定常状態 ODE: dX/dt = X(1−X)/T_l − X/T_s → **X_eq = max(0, 1 − T_l/T_s)**
- ⚠ 論文内不整合の記録: VI.1 節本文は η₁=.25, η₂=.4 と表記(II.4 節の 0.1700 と矛盾)。
  再現時は II.4 節のガンマ関数式を正とする

### 入植状態の表現(マーク場 (b)(c) の設計素材)

- 3状態: unsettled / targeted / settled。重複標的なし。迎撃時間最短の系を狙い、
  旅行時間超過なら**待つ**(先回り発射なし)
- 定常状態計算では寿命 T_s で死亡 → unsettled に戻ってから再標的可(再入植)
- η ≲ 1 でシミュレーションが解析解より高い X: 密度揺らぎポケット内の**相互再入植**
  (η~0.25 でペア、~0.4 で ~10 系のサブグループ)→ マーク場 (c) クラスター族の物理的動機

## 3. 境界条件インターフェース仕様(憲法第3条3項)

### 3.1 供給される境界条件ベクトル

境界条件層は排除地図の格子点ごとに θ_gal = (f, v_p, d_p, T_s, T_p) を受け取り、
CN19 の解析式で導出量を計算して返す:

```
BoundaryConditions(θ_gal) → {
  X_eq:      定常入植割合 = max(0, 1 − T_l/T_s)     # CN19 ODE 平衡解
  v_front:   前線速度 = max[𝒱ν_s, ν_l]·v_p          # 前線族の速度
  Δ_front:   前線厚み = ν τ_l / ln2 · d_p            # 前線族の厚み
  T_l, T_c:  実効打上げ周期・遭遇律速時間            # 到来率の規格化
}
```

適用範囲の注意: CN19 の解析式は η ≲ 1 でシミュレーションと乖離(相互再入植)。
X_eq はその解析下限として使い、乖離域はマーク場 (c)(Phase R 帰結待ち)の守備範囲とする。

### 3.2 境界層 → マーク場 f(x,v,t) の写像(第4条3項の標準実装への翻訳)

**(a) 帰無モデル(定数場)**
```
P(marked | x, v, t) = X_eq(θ_gal)        # 一様独立。パラメータは実質 f のみ
```
CN19 との整合: 遭遇律速レジームで前線構造が洗い流された定常状態に対応。

**(b) 前線族(シグモイド場)**
```
s(x, t) = [ n̂·(x − x₀) − v_front·(t − t₀) ] / Δ_front
P(marked | x, v, t) = X_eq · σ(−s)                        # σ = ロジスティック
                    × K(v; n̂)                             # 運動学相関項
```
- パラメータ: 通過方向 n̂(事前: 一様球 + 銀河中心バイアス変種 — Wright+21 RNAAS が
  前線の銀河中心向きバイアスを示す)、通過時刻 t₀、厚み Δ_front(CN19 式で θ_gal から導出)
- **K(v; n̂) が第4条3(b) の「前線方向と恒星運動学の相関構造」**: CN19 の低密度レジームでは
  前線は分布の裾の最速星(𝒱=2–3.5)が運ぶ。よって前線先端側では「前線進行方向への
  速度成分が大きい星ほどマーク確率が高い」。v1 実装は
  K ∝ 1 + β·max(0, v·n̂)/σ_v(β は前線レジームで CN19 の 𝒱 から較正、遭遇律速で β→0)

**(c) クラスター族** — 区画確保のみ(第4条3項)。CN19 の相互再入植クラスター
(η~0.25–0.4 のサブグループ)が理論的動機。Phase R の閾値定理待ち。

### 3.3 カタログ層の不可知性(第4条2項)

カタログ層が見てよいのは `MarkField.p_settled(x, v, t) → [0,1]` のみ。
(a)(b)(c) の実装詳細・θ_gal への依存は境界条件層に閉じる。Phase 3 で静的検査
(import 依存の走査)をテスト化する。

### 3.4 窓外のハイブリッド接続(第3条3項)

±窓内: 実カタログの接近イベントに写像後のマーク場を重ねて到来統計を計算。
窓外(|t| > 個別ホライズン): 統計銀河(CN19 型 Poisson 場 + 上記境界条件)の
到来率 λ_gal = X_eq/T_c に接続。**接続点で率が連続であることが整合性チェック**
(G3-4 定常性アンカーの外縁版)。窓外の排除地図出力は「判定不能」(第5条6項)。
