## 裁定2 — 公開先: 三面構成+公開順序

- **Zenodo(本日公開・最優先)**: 両版 PDF+公開 JSON 3本+MANIFEST+リポジトリアーカイブ(tar.gz+sha256)を単一レコードに同梱(付録B・C の参照先が同梱アーカイブであるため必須)。Creator に ORCID 0009-0005-3401-9230 紐付け。数学論文 DOI を Related identifier に。
- **GitHub(wake-atlas)**: 全量 push+タグ v1.0-zenodo+Release(Zenodo と同一 tar.gz+sha256 本文記載)。README(タイトル・DOI バッジ・再現手順・ライセンス併記・数学論文リポジトリへの相互リンク)。
- **Jxiv(和文版)**: 新規投稿手続きを開始するが、**先方確認を待たずに Zenodo を先行公開**(タイムスタンプ優先 — 前田さん裁定)。Jxiv 掲載確定後に Zenodo メタデータへ相互参照を追記。
- 相互参照: Zenodo ⇄ GitHub ⇄ 数学論文 DOI(公開後にメタデータ編集 API で閉じる)。

## 裁定3 — シミュレータ: GitHub Pages(wake-atlas)で公開

- Pages URL を Zenodo 説明文と論文付録D に記載(URL 確定後、publish 前に題箋・付録D へ反映)。

## 公開手順(実行系への指示)

1. 三点セット監査 → 再現性検証(クリーン環境)→ 両 PASS を報告
2. Pages 公開(シミュレータ)→ URL 確定 → 論文付録D・Zenodo 説明文へ反映 → 最終再コンパイル+ゲート再走(1コマンド)
3. Zenodo デポジット準備(DOI 予約 → 題箋追記 → リリースコミット → アーカイブ生成+sha256 → メタデータ → アップロード+md5 照合 → publish)。トークンは前田さんが再発行・read -s 方式で設置(作業後削除)
4. GitHub push+タグ+Release → Zenodo 相互参照(メタデータ編集 API)
5. Jxiv 新規投稿手続き(和文版)— 掲載確定後に相互参照追記
6. 台帳へ DOI・URL・sha256 を転記 → **Phase 5 クローズ審査報告**(三点セット監査・再現性検証の証拠込み)
