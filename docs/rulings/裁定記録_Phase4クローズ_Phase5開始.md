## 裁定1 — Phase 4 クローズ: 可

- 出口条件3点(時変グラフ v1 のカタログ自動導出 / 経路存在統計の G1 収束 / G2 一致)の充足を確認。
- 中核結果の採録: **推進剤最小の来訪経路(単一乗換)の離脱 Δv ≈ 5.8 km/s**(アンサンブル中央値 5.7–5.9、存在確率 100%)— 経路が特定星に依存しない網の統計的性質であることを含めて論文第3層節の看板に。外部整合(直接通過 2件 = HD 7977・GJ 710)を検証記録に。
- G2 実戦成果の系譜に4件目を追加: 長い脚のエピサイクル位相回転による単純反復の発散を検出・シューティング法で修正(miss < 0.1 mpc)。
- v1 制限(多段 DP・全数値再抽出アンサンブル・恒星質量実値)は v1.1 予約として明示 — 承認。
- **付帯1**: E9 較正(実測 ν で m 閾値 1.5–2.0 に上方シフト)の**排除地図 (c) 族許容域レイヤへの波及確認**。f* は λ ベースで不変のはずだが、(c) 族レイヤは m 閾値依存のため、E9 反映済みかを確認し、未反映なら排除地図 v1.0.1 として差分再生成(変更履歴をメタデータに記録)。
- E9 の科学的採録: 「実測運動学は等方近似より入植前線に厳しい(閾値約1.5倍)— C2 の等方仮定は保守的でない方向の近似」を地図凡例(反映済み)と論文理論節に。純等方版 C2(数学論文の開放問題1)に実測からの需要が付いた形として、開放問題の意義付けに使用。
- クローズコミットを許可。メッセージ例: 「phase4: close (flyby network v1, min-Δv 5.8 km/s, E9 recalibration)」

## 裁定2 — Phase 5(最終フェーズ)開始: 承認

構成は PHASES 1.2 どおり(論文日英 / カタログ+排除地図 JSON 公開版 / ブラウザシミュレータ / 三点セット監査 / 再現性検証)。段取り:

1. **論文執筆を先行**。数学論文で確立した組立手順を流用: 目次案 v0 の裁定 → 骨格 → 編纂 → 品質ゲート(grep 検査・引用機械検証・数値一貫性)→ 参謀通読 → 前田さん公開承認。最初の付議 = 目次案 v0。
2. 新規性主張の規律(憲法第11条1項)を骨格段階から適用: 主張は「実カタログ上の接近統計に入植動力学を重ねた点」に置き、第1層は検証台として記述。過大主張の禁止。
3. **シミュレータ設計セッション**(前田さん+参謀、物理→美学)は論文骨格の固まった直後に実施。データ供給仕様 v0 は確定済み。
4. 三点セット監査(論文・カタログ/地図・シミュレータの数値相互照合)と再現性検証(クリーン環境でのフルパイプライン再実行)を出口条件として維持。
