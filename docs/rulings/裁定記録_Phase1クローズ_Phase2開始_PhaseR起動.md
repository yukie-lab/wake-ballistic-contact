## 裁定2 — Phase 2 開始: 承認(要件3点付き)

- 初手は付議どおり: DR3 6D カタログ取込 → 検疫・ホライズン適用 → 誤差 MC 本計算。
- **要件(i) 完備性ビン幅の正則化管理**: ビン幅暴走の実証(既定 21.6 / 粗ビン 23.5 / 細ビン 56.1)を受け、完備性ビン幅を s_floor と同族の「隠れ正則化パラメータ」としてコンフィグ化し、既定値を裁定ログで固定、感度スキャンを常設する(PHASES 1.2 作業項目6)。
- **要件(ii) s_floor 第二段の前倒し**: カタログ取込直後に gaiaunlimited 実分散で σ(S) を差し替え、カバレッジ目標(例: ≥95%)と併せて第二段裁定の材料を採取(裁定ログ#4 宿題の履行)。
- **要件(iii) 補正系統の分離**: 本計算の DR3 完備性は gaiaunlimited 主経路(フォーク3裁定・案A)。GDR2mock 流儀は G3-3 の BJ+18 同一手法再現専用であり、本計算の補正系統に流用しない。
- **運用条項: 冒頭 5% 定常性速報**: 本計算の冒頭 5% 時点で G3-4 定常性の速報チェックを実施(全量完了後に不合格を知る事故の予防)。速報で異常があれば即停止・報告。
