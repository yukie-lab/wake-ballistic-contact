## 裁定1 — 検疫拡張 bit5「rv_faint_suspect」: 承認【v1 ゲート解除】

- 定義: **G > 13.5 ∧ |RV| > 150 km/s**(暫定値として承認)。感度スキャン(|RV| 閾値 120/150/200 の3点)を実施し文書化すること。Katz+2023 の DR3 RV 品質指針を参照根拠として明記。
- 運用: bit3 と同型 — 要手動審査・個別イベント判定から除外・率は**両建て報告**(suspect 込み / クリーン)。
- **手動審査の判定基準(精密化)**: **接線速度との整合検査**を標準手続きとする。本物のハロー星は RV と固有運動の両方がハロー運動学を示す。円盤的な固有運動なのに RV のみ極端な星はアーティファクトの典型署名。|RV| 150–300 km/s には実在のハロー星が存在するため、bit3 の HVS ホワイトリストと同様、確認済み実星の救済経路を必ず持つこと。
- 記録: 「等級依存の系統は値の異常検疫(bit3)と誤差の異常検疫(rv_error カット)の両方をすり抜ける第三のモード」という発見を、DR3 系接近研究への方法論的警告として論文素材に採録(9件中 bit3 捕捉 2件、という数字込み)。

## 裁定2 — 2種監査の統制領域内超過24星: t_pot 第3ホライズンを採用

- 実効ホライズンを **min(t_h, t_pot)** に拡張する(flag-only は不採用)。
- 根拠: 24星が全て |t|≥4 Myr 遠端に分布 = ポテンシャル不確かさの時間成長系統。憲法の非対称原理(偽の判定可能より判定不能)に従い、既存の個別ホライズン機構へ組み込む。
- 実装後、2種監査の最終値(予算比)を出口審査報告に反映。

## 裁定3 — G1 合格枠組み: 承認

- G1 の合格対象は MC/標本収束(項目1–4)。母集団統計誤差(λ@5pc の 14.7%、@1pc の重い裾 [12.0, 59.7])は収束不良ではなく**測定の誤差棒**として報告する。
- 少数星支配の重い裾は Phase 2 の科学的対象(塊状構造・単一星支配)と接続する事実として扱い、G1 不合格と混同しない。

## 裁定4 — C(t,d) ビン幅既定値: スキャン後に安定域で固定(基準明文化)

- 3点走査の結果から、**隣接ビン幅間の率変化が誤差棒の半分未満**となる安定域の値を既定に固定。
- 裁定ログには値と選定基準の両方を記録(ビン幅=隠れ正則化パラメータの管理 — 裁定ログ#6 の履行)。

## 裁定5 — 著者照会リスト: 承認(表現水準の規律付き)

- BJ 5件+FP26 7件+GJ710/BB22 単位仮説を一括照会リストとして確定(送付は Phase 2 完了後・従前どおり)。
- 表現水準: 照会文では断定を避ける。例: FP26 へは「spurious parallax 説は支持されない」ではなく「我々の再構成では会計・母集団規約差が主因と示唆される。貴殿の帰属と整合するか確認したい」の水準。**反証は論文で、照会は対話で。**
