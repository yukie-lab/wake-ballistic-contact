# シミュレータ実装指示書 — WAKE ブラウザシミュレータ v1

> 2026-08-17 / 裁定ログ #18 / 設計セッション(前田さん+参謀)の結論
> 仲裁ルール: 物理 → 美学(憲法第11条3項)。データ供給仕様 v0+設計セッション材料(04)を前提とする。
> 実装は Three.js。過去作の規律(検証ハーネス先行・実測則・物理由来の視覚)を踏襲。

## 1. 動線の骨格(具体 → 構造 → 抽象 → 自分ごと)

1. **入口 = 航跡タイムライン**(単一画面): 過去1000万年〜未来1000万年、太陽近傍の接近イベントの帯。有名星(ショルツ星/GJ710/HD7977)ラベル常時表示。
2. **星タップ → フライバイ網 3D**: 当該星がノードとして浮かび、時空軌跡と網の辺が展開。最小乗換経路のハイライト+Δv 表示。
3. **f* 常時表示 → 排除地図**: 画面端に現在の航跡群から導かれる f* 境界のミニ表示を常時置き、タップで排除地図(R–f ヒートマップ+L/v スライダー)が全画面に開く。条件付き確率文はスライダー値で動的に組み立てて表示。
4. **出発モード**(視点反転トグル): 「人類の次のバスはいつ来るか」。flyby_network_v1 の辺の逆読みのみ(新規軌道計算は禁止 — 続編棚)。

## 2. 物理の裁定(セッション結論)

### 裁定1 — 不確かさの一級市民化: 軌跡は「束」で描く
- 時間再生時、各星は単一軌跡ではなく**誤差アンサンブルの束**(サロゲート 16〜32 本の半透明軌跡)として動く。計算の実体(誤差 MC)をそのまま見せる — 「測量であって証明ではない」の視覚化であり、「航跡(WAKE)」の題名の絵解き。
- 接近イベントは CI90 リボン、個別ホライズン縁はフェード(証拠の地平線)。suspect(bit5)はトグルで半透明化(両建ての可視化)。
- 束の本数は性能実測で確定(M4 実測則: まず 16 で組み、余裕があれば 32)。

### 裁定2 — 出発モードの時間: 過去は「乗り損ねたバス」として残す
- モード切替時、過去半分を暗転させず、**出発済みの便**として色分け表示。ショルツ星 = 「人類は約7万年前、0.25 pc まで来た便を見送った」の注記。未来側は乗車可能便(GJ710 = 次発、+1.29 Myr、乗車 Δv 表示)。
- 出発モードの全計算は既存 JSON の読み替えに限定。

### 裁定3 — 視覚は全て本物に基づく
- **位置**: カタログ v1 の実測 6D(誤差束込み)。恒星の固有名・Gaia ID を表示可能に。
- **色**: Gaia 実測 BP−RP から黒体近似で色温度へ(過去作の物理由来スペクトル彩色の系譜)。
- **大きさ**: 実測等級(G)から見かけの明るさとしてスケーリング(距離とともに変化 — 時間再生で近づく星は明るくなる)。誇張スケールを使う場合は UI に倍率を明示。
- 排除地図の色は物理量由来のマッピングとし、具体のパレット(「訪問済みのはず」= 深い琥珀系 / 「沈黙と整合」= 夜空系、の方向性)は実装後の美学レビューで前田さんが最終裁定。
- 背景星は f32 精度対策(過去作の教訓)を最初から適用。

## 3. 憲法制約(全画面・削除不可)

- フッタ「測量であって証明ではない / This is a survey, not a proof」常時表示
- 判定不能(R>5pc・ホライズン外・S<floor・suspect)の常時明示 — 空白やゼロで埋めない
- 条件付き確率文に母集団(FGK+早中期M)・完備性・太陽λ規約・安全側の向きを内蔵
- 定理レイヤ表示時: 三値凡例+等方化近似・数値閾値(E9 実測較正 1.5–2.0)の注記
- 数学論文 DOI・本体論文・データ MANIFEST への参照リンク

## 4. 実装の作法(過去作の規律)

- **検証ハーネスを最初の成果物に**: 描画前に、JSON 読込値と論文数値(f*=5.0e-3 / λ=4.49 / Δv=5.8 / GJ710 0.0519pc@+1.294Myr)の一致を自動検査するハーネスを組む。三点セット監査のシミュレータ側の錨。
- instanced mesh を基盤構造に(過去作の基本則)。目標 60 fps @ M4。
- データは供給仕様 v0 の3ファイル+MANIFEST のみから読む(ハードコード数値の禁止 — 監査の一意性)。
- 実装中の物理/美学の衝突は仲裁ルール(物理優先)で実行系が仮決定し、美学レビューで前田さんが最終裁定。
