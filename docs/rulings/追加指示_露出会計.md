# 追加指示 — 露出会計の規約突き合わせ(Phase 2 出口の必須要件に追加)

> 2026-08-17 / 前田幸枝(参謀検算に基づく)
> 背景: G1 で同定された露出正規化(星ごと 2·min(T, t_h))により λ@1pc = 20.3±7.0 /Myr が
> C(t,d) なしで BJ 系と整合した。これは「公刊2陣営の分裂は補正深度の関数」仮説を
> 「分裂の相当部分は完備性以前の露出会計に由来する可能性」へ精密化する発見である。
> ただしこの主張は、両陣営の会計規約の正確な再構成の上でしか立たない。以下を実施すること。

## 1. 規約の条文突き合わせ【カタログ v1 の前に必須】

BJ+18 と FP26 のそれぞれについて、一次資料の記載から以下を条文レベルで再構成し、
対照表(docs/phase2/exposure-accounting.md)にまとめる:

- 率の分母(露出)の定義: 窓 T は全星一律か、星ごとの有効窓か。有効窓の場合の定義は何か
- 時間方向の打切り(遠時刻で誤差が成長するイベント)の扱い: 分子から除外か、
  重み付きで算入か、完備性補正側で処理か
- 判定不能相当のイベント(彼らの用語で何と呼ばれているか)の分子・分母での扱い
- 完備性補正 C の定義域: (t_ph, d_ph) 依存か、一律定数か、その構成法

その上で、本機構の露出正規化 λ=20.3 が
(a) BJ+18 規約の再現なのか、(b) FP26 規約の再現なのか、(c) 第三の規約なのか、を明文で判定する。
記載から確定できない項目は「不明」と正直に記録し、推測で埋めない(著者照会リストに追加)。

## 2. 交差検証【確証バイアスの検疫】

20.3 と 19.7 の一致が規約の偶然の一致でないことを、次の交差実験で確認する:

- 本機構のデータに **FP26 の規約(§1 で再構成したもの)を適用**した λ を計算する。
  FP26 の 10.6±4.5 に近づくなら「分裂=会計規約差」仮説は強く支持される。
  近づかないなら、分裂には会計以外の成分(完備性構成・カタログカット等)が残る —
  その場合は残差の帰属を分解して報告する
- 同様に BJ+18 規約の適用値も算出し、三規約(BJ 再構成 / FP26 再構成 / 本機構の露出正規化)の
  値を同一データ上で並べた表を作る。この表が論文の中核比較の骨格になる

## 3. C(t,d) 参考表示層の役割の再定義

- 旧定義「11.7 を BJ 系へ持ち上げる補正深度の検証」を廃止する(11.7 は下方バイアス値と同定済み)。
- 新定義: **露出会計(時間方向の打切りを分母側で扱う)と完備性会計 C(t,d)(同じ物理を
  分子の補正側で扱う)が、同一の到来率に整合することの確認**。二つの帳簿が合えば、
  それ自体が率推定の頑健性の証明になり、合わなければ差分がどちらかの帳簿の穴を指す。
- 実装は従来裁定どおり(GeDR3mock 由来・参考表示のみ・排除地図の条件文には不使用)。

## 4. 論文への反映規律

- 「2陣営の分裂を説明した」という表現は、§2 の交差検証が支持した場合にのみ、かつ
  「会計規約の再構成に基づく」という限定付きでのみ使用する。§1 に「不明」項目が残る場合は
  「可能性の指摘+著者照会予定」の水準に抑える。GJ 710 付録で確立した信用を守ること。
- 露出正規化の発見自体(11.7 の同定と 20.3 への修正)は、規約対照表とともに
  手法節の中核素材として採録する。

## 5. 順序

新 MC 完走 → flash 再確認 → **本指示 §1–2** → C(t,d)(§3 の新定義で)→ カタログ v1
(v1 のメタデータに採用露出規約を明記)→ 2種監査 → 塊+BANYAN → 出口審査報告。
§1–2 をカタログ v1 より前に置くのは、v1 の率メタデータが規約明記を要するため。
