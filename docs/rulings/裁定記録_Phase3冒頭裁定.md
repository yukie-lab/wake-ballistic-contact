## 裁定1 — 付議1(マーク場 (c) パラメータ写像): 条件付き承認

**承認事項**: 写像表(R=d_p / τ=d_p/v_p / p=f_set / T_s 直接 / ρ,ν 実測固定)、λ(R) の区分冪補間(実測アンカー {4.49, 27.5, 137.3}、R<1pc 外挿フラグ、R>5pc 判定不能)、λ の選択(クリーン主・suspect 両建て)、(c) 族の「クラスターなし近傍」実測整合域、逆向きチャネルの地図脚注。

**条件(i) K_mix 憲章【最重要】**: 付議材料の「K_mix ≥ 20 はほぼ常に成立」は**誤り**と認定する。実行系自身の式 T_s ≳ 0.8 Myr·(R/pc) に R = d_p = 3.07 pc(CN19 標準 10 lyr)を代入すると T_s ≳ 2.4 Myr が必要であり、CN19 の L 軸スキャン域(T_s = 0.1–1 Myr)は**全域で不充足**。充足は R ≲ 1 pc の短航続域に限られる。よって:
- (v, R, L) 格子全域で K_mix・Λ̄ 条件の充足マップを**地図生成に先立って**作成する
- 定理レイヤは三値凡例で塗る: **「C2 保証(生存可能)」/「定理沈黙(仮定域外)」/「絶滅側は全域で数値・平均場のみ(定理なし)」**
- 定理沈黙域の判定材料は数値閾値 m ≈ 1.0–1.3(E1)のみである旨を凡例に明記
- 根拠の再確認: 定理 C2 は十分条件であり仮定の外では何も言わない。絶滅側の定理 A は SIR 変種にのみ成立し、完全モデルの絶滅閾値は開放問題(本プロジェクト自身の反証命題)。「生存不能」を定理で支えることは全域で不可能

**条件(ii) 物理率レイヤ**: クリーン λ(FGK+早中期M)は探査機にとっての物理的遭遇率の**下界**にすぎない(探査機は Gaia の選択関数に従わない)。主計算はクリーン λ(保守的・監査可能)とし、二帳簿の橋 ×5.3 を掛けた**モデル明示の参考レイヤ**を併記する。保守性の向き(λ 過小 → 「訪問済みのはず」領域が縮む = 主張が安全側)を凡例に明記。

**条件(iii) 太陽 λ 規約注記**: 地図の λ は太陽の実測到来率であり星平均ではない旨を条件文に含める(Phase 2 規約対照表の教訓)。

**条件(iv)**: λ 選択の両建て運用は原案どおり。
