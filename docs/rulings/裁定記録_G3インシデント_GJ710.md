# 裁定記録 — G3 インシデント(GJ 710 d_ph 公刊間分裂)

> 2026-08-14 / 裁定者: 前田幸枝(参謀チャットの裁定案を承認)
> 対象: docs/phase1/02-g3-incident-gj710.md(憲法第6条に基づく停止報告)
> 本文書受領後、実行系は停止を解除し、裁定ログへ転記の上、G3 台帳を更新すること。

---

## 裁定1 — 停止解除: 可

- 原因究明完了と認める。根拠: 機構側4手法(LMA 閉形式算術・DC95 積分・MWPotential2014 積分・コード非共有エピサイクル独立実装)の相互一致(0.050–0.052 pc)+ 公刊2系(dlFM22 N体 / BB22 積分の d)との一致。LMA が手計算可能である点をもって機構側検証は尽くされている。
- 参謀チャットによる独立再導出でも確認済み: v_T = 4.74047×10⁻³ × 0.428 × 19.09 = 0.0387 km/s → d_ph = 0.0513 pc、t_ph = 1.294 Myr。BJ22/FP26 の d_ph が記載入力から導出不能であることも独立確認。軌道曲率実測 ≤0.002 pc は分裂幅 +0.013 pc を説明しない。

## 裁定2 — G3-2 厳格帯の基準系: (a) dlFM22 系に規定

- 新しい厳格帯: **t_ph 1.26〜1.33 Myr / d_ph 0.048〜0.056 pc**(dlFM22 の CI90)。緩和帯は不変。
- 位置づけ: 厳格帯の定義「同一入力での再現」は、出力が入力から導出可能な系に対してのみ意味を持つ。BJ22/FP26 の d は記載入力から導出不能であることが実証されたため、基準系から外す。
- **本裁定は「通すための帯拡大」ではない**(G3-2 は現に緩和帯 PASS・dlFM22 系厳格相当の再現済みで救済不要)。行うのは合格帯の事後拡大ではなく**基準系の再指定**であり、憲法 1.1 G3-6(事後拡大禁止)と抵触しない。
- BJ22/FP26 との緊張は消さず、Phase 2 の科学的検討事項として保持する。
- 手続き注記: 憲法 1.1 第6条 G3-5 により合格帯は裁定ログ管理であるため、本裁定をもって固定手続きは完結する(条文改正は不要。インシデント報告の「第10条手続き」言及は 1.0 時代の残置表現として読み替え)。

## 裁定3 — 公刊分裂の扱い: 付録採録・著者照会は Phase 2 後に延期

- 論文付録に採録する。内容: DR3 入力からの GJ 710 d_ph 系統検証(4手法証拠鎖)、公刊2陣営の整理、BJ22/FP26 の入力からの導出不能性。
- **BB22 単位仮説を付録素材として記録する**(参謀検算の副産物): 1 pc/(km/s) = 0.97779 Myr。真値 1.294 Myr ÷ 0.97779 = 1.3234 ≒ BB22 報告値 1.324±0.026。BB22 の t のみが孤立し d は 0.052 陣営と一致するパターン、および同論文線形法の行(t=1.325/d=0.051)を単一仮説で説明する。**断定はしない**(確定は著者照会のみ)。付録記載時は算術ごと提示。
- 著者照会(BJ 系・BB22)は Phase 2 完了後、全カタログ規模の比較結果を持って一度で行う。単発照会より立場が強く、相手の検証負担も小さい。

## 裁定4 — G3-1 出所ラベル訂正: 追認

- 「DR3系」→「dlFM22(Dupuy+2019 入力)系」。帯の数値は不変。
- 解釈節の素材として記録: ショルツ星は Gaia DR3 にアストロメトリ解が存在しない(2パラメータ解のみ)。直近70万年最大のフライバイが判定不能規律の実例であることが一段強化された。

## 裁定5 — G3-3 への同型プロトコル予約(先読みの旗)

- GJ 710 で露呈した d_ph 系統が BJ 系パイプラインの星非依存の性質である場合、G3-3(BJ+18 同一手法再現)の頻度再現も文献側要因で崩れ得る。
- **G3-3 厳格帯が不合格となった場合も本件と同一プロトコルを踏むこと**: 停止 → 機構側独立証拠鎖 → 裁定。自動救済は設けない(ゲートを事前に弱めない。処理経路の予約のみ)。
- **インシデント証拠鎖の標準テンプレートを固定する**: (i) 閉形式算術(手計算可能な独立導出)、(ii) 刻み幅収束、(iii) コード非共有の独立実装照合(G2)、(iv) 公刊相互照合。以後の G3 インシデントはこの4点セットで報告すること。
