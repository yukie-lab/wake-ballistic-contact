## 中核結果

- **直接通過(≤0.1 pc・±10 Myr・クリーン)は 2 件 = HD 7977・GJ710**(既知の
  有名星と一致 — 実装の外部整合)
- **推進剤最小の来訪経路(単一乗換)**: 任意の通過星に搭乗 → 離脱 Δv **≈ 5.8 km/s**
  で GJ710 級の至近通過に乗り継ぎ可能。誤差アンサンブルでも中央値 5.7–5.9 で頑健
- 保守規約: 離脱 Δv は全額推進剤(共動 v∞≈0 でフライバイ加速不可)、
  到着側のみフライバイ利用可 — Δv は上界側
