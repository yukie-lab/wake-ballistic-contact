### 既定値の裁定伺い(裁定4 の厳格基準が不成立のため)

走査の実相: 率は 46.5 → 23.7 → 20.4 → 27.1 → 20.7 と**非単調**(細側は空セル×1/C
発散、粗側 (2.0,1.0) はビン境界エイリアシングの外れ)。「隣接間変化 < σ/2」を
満たす対は存在しない。提案:
- **既定 = (Δt, Δd) = (1.5, 0.75)**(プラトー対 20.4/20.7 の中心、C<0.01 率最小 0.2%)
- **格子系統帯 ±15%**(非発散域 20.4–27.1 の広がり)を参考表示層の誤差に畳み込む
  (BJ の f_c=0.1 と同思想の系統項)
- 代替案: BJ 正準 (1.0, 0.5) を維持し G3-3 との比較可能性を優先(+同じ系統帯)
いずれも参考表示層の内側の選択であり排除地図の条件文には影響しない(裁定ログ#8)。
