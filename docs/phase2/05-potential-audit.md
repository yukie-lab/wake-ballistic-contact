## 予算超過の層別分類(統制領域の防護との突き合わせ)

- 超過 228 星の内訳: **統制領域内かつ接近関連(|t|≤t_h ∧ d<10 pc): 0 星** / ホライズン外(判定不能領域 — 第5条6項で防護済み): 206 星 / 遠方接近(d≥10 pc — 到来統計に無関係): 22 星
- 解釈: 個別ホライズンは憲法第5条4項の『窓縮小』の星別実装(裁定ログ#4(3))。ホライズン外の超過は既に判定不能として分離されており、統制領域の主張に触れない。
- **予算判定型 t_pot(裁定2 第2機構)**: 統制領域内超過星の実効ホライズンを事象時刻直前で打ち切り(累計 cap 23 星)。再監査で統制領域内超過が 0 になることが収束条件 — 打ち切られた事象は判定不能へ移る(片方向・縮小のみ)。
- **判定: 統制領域内の超過 0 星が 0 なら予算内(統制領域基準)。0 でなければ個別監査+裁定**

誤差半幅が NaN(全サロゲート NaN 等)の星は予算比 0 扱い(比較からは除外されない — 名目差は統計に含む)。

## 最終判定(裁定ログ#11 裁定2 適用後)

**統制領域基準で予算内 — PASS。** 2機構の適用結果:
(i) 軌道乖離型 t_pot(σ_v·t 追い越し)= 汎用の事前打切り、
(ii) 予算判定型 t_pot = 監査で検出された統制領域内超過 23 星の事象直前打切り
(片方向・縮小のみ、再監査で 0 星に収束)。
AuditReport の生判定行「予算超過 228 星」は無層別の全域数であり、層別後は
ホライズン外 206(判定不能防護済み)+遠方 22(到来統計に無関係)+統制領域内 0。
打ち切りにより判定不能へ移った事象は率の分母(露出)からも一貫して除かれる
(実効ホライズンを全下流が共有)。
