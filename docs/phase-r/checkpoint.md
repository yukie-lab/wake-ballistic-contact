## 0. 形式化(規約 — wake_r/device.py と一致)

モデル M(ρ, ν, R, p, τ, T_s):
- t=0 に強度 ρ の Poisson 点過程、各点に iid 速度 v_i 〜 ν(3D、既定は楕円体ガウス)。
  x_i(t) = x_i + v_i t(等速直線)。任意の t で配置は再び Poisson(ρ)(時空定常)。
- ペア (i,j) の接触窓 T_ij = {t : |x_ij(t)| ≤ R} は区間 [α_ij, β_ij](弾道運動 ⇒ 高々1回)。
- 伝播(**進入駆動・撃ちっ放し**): マーク済み i が生存中 [m_i, d_i) に窓 T_ij と重なるとき、
  時刻 a_ij = max(α_ij, m_i)(かつ a_ij < d_i)に**順序対ごとに一度だけ**確率 p の試行。
  成功なら j は a_ij + τ にマーク。d_i = m_i + Exp(T_s)。死後の再マーク可。
- 種: 原点付近の1点を t=0 にマーク。生存 = マーク生存集合が全時刻非空(⇔ 総マーク数無限)。

**基本量**: deg := (4π/3)ρR³(定常で R 内にいる期待数)、
λ := ρπR² E|v_rel|(新規進入率。E|v_rel| は ν の独立2標本の相対速さ期待値。
等方 3D ガウス σ_1 成分なら E|v_rel| = (4/√π)·σ_1・... 要固定)、
**m := p·(deg + λT_s)**(1マークあたり期待試行対象数 × p)。
無次元制御: (ρR³, pλT_s, K := E|v_rel|T_s/R)。単位は R=1 に取れる(スケール不変)。

## 1. 主張の木(状態: ✅証明済み / 🔶証明スケッチ / 🧪数値検証済み / ❓予想 / ❌棄却)

- **C1 ❓→🔶(絶滅・厳密化狙い)**: m < 1 ⇒ 総マーク数の期待値有限 ⇒ a.s. 絶滅。
  手法: 時間順序付き有向路の第一モーメント(Mecke/Campbell)。各步の因子 ≤ p(deg+λT_s)。
  経路上の条件付けを Poisson の独立増分で処理する。**セッション1で証明を書く**
- **C2 ❓(生存)**: ∃c₀(≈1?): 疎領域で m > c₀ ⇒ 正確率で生存。
  手法候補: 時空ブロック+方向付きパーコレーション優越(弾道運動の新鮮領域性:
  vT_s ≫ R なら子の遭遇円錐は親とほぼ独立)。まず数値で真の閾値の位置を測る
- **C3 ❓→✅級(静的極限)**: v≡0 では過程はボンド希釈 RGG(ρ,R; p) のパーコレーションと
  同値(死亡は無関係: 試行はマーク瞬間に全て即時発生するため)。証明は書けば数行
- **C4 ❓(単調性 — 層3の中核)**: ν → s·ν₀ のとき p_c(s) は s に単調非増加。
  補題(証明可能見込み): E[使用可能ペア数] = deg + λ(s)T_s は s に単調増加
  (deg 項は速度非依存 — 定常性より)。完全な生存単調性は結合(coupling)を試みる。
  ⚠ 注意: 進入駆動規約だから成り立つ見込み。滞在時間要求型なら非単調のはず(規約依存性を明記)
- **C5 ❓(交叉描像)**: 実効閾値は「よく混ざる極限(分枝: m≈1)」と「静的極限
  (パーコレーション: p·deg ≈ 2.7…)」の間を K = E|v_rel|T_s/R で内挿する。
  **層3の定量版: p_c(s) 曲線の実測が最初の主要実験**
- **C6 ❓(前線・層2)**: T_s=∞、ν 非有界(ガウス)なら R(t)/t → ∞(前線は次第に速い
  マーク粒子が運ぶ — CN19 の 𝒱(N個中最速)ヒューリスティックの無限系版)。
  ν 有界なら線形前線+形状定理予想。WAKE 本体との接続: 有限カタログ = 有限 N の影
