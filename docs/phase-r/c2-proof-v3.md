**補題X(最終形)**: 𝒢_{i−1} を構成の全開示(カプセル PPP・対コイン・追跡粒子の
寿命判定)とする。構成未接触の候補 j への成功到着(時刻 a)について、
P(j が t* にマーク済み生存 | 𝒢_{i−1}, 到着) ≥ (1−δ)·e^{−(t*−a)/T_s}、

**残る本質**: 𝒢 は j の寿命と**動力学経由で**相関する(例: 追跡粒子が構成外の
到着でマークされた事実は「近傍の誰かが生きていた」ことを開示し、j がその「誰か」
である事後確率だけ j の履歴が歪む)。主張の根拠(未証明の直観):
観測された rogue 事象の原因候補は局所的に Poisson 個数(≫1)あり、
特定の j への事後影響は O(1/期待原因数) に薄拡散する。

「原因の交換可能性」)。1事象あたり影響 O(1/N)、構成が観測する rogue 事象数
× O(1/N) の総和が δ に収まることの勘定。
