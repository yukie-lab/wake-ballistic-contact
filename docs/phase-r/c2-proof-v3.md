## 補題X(単離された核心)【状態: 未証明 — 最終形への還元済み】

**還元1(タワー性)**: 方向付きパーコレーション支配に必要なのは
P(開_i = 1 | 開_{<i}) ≥ 1−ε のみ。全開示 σ-加法族 𝒢_{i−1} ⊇ σ(開_{<i}) での
下界から従う(タワー性)。ゆえに補題Xは全開示条件付きの言明でよい。

**還元2(補題0の限定適用)**: 修正6により、候補は「構成が一度も判定していない粒子」
に限る。その候補 j の寿命コイン列は 𝒢 に**直接は**現れない。

**補題X(最終形)**: 𝒢_{i−1} を構成の全開示(カプセル PPP・対コイン・追跡粒子の
寿命判定)とする。構成未接触の候補 j への成功到着(時刻 a)について、
P(j が t* にマーク済み生存 | 𝒢_{i−1}, 到着) ≥ (1−δ)·e^{−(t*−a)/T_s}、
δ = δ(m₁, K_mix) は構成の密度パラメータで小さくできる。

**証明(セッション6 — spread-thin は不要だった。私有コイン独立性で閉じる)**:

*観察1(失敗の必要条件は私有コイン)*: 候補 j の失格 Q̄_j = {j が t* にマーク生存で
ない} は、到着 a の場合分けごとに次を含意する:
- 場合 (i)(ii)(未マーク/死亡済み → 我々が(再)マーク): 失格 ⇒ **我々の到着が張った
  新鮮な寿命コイン** L^{our}_j < t* − a(他の episode による救済がなければ、では
  なく — 救済があれば失格でないから、失格 ⇒ L^{our}_j 不足は必要条件)
- 場合 (iii)(生存中 → 空振り): 失格 ⇒ **現行 rogue episode の残余** R_j < t* − a
いずれも「j の私有コイン1個の不足」が必要条件。A_j := その事象と置くと Q̄_j ⊆ A_j。

*観察2(私有コインの共同独立性)*: 時刻 a までの全条件付け(𝒢_{i−1}、
場合の割当、エポック内環境、他候補の到着状況)は、各粒子の寿命コインを
**指示関数経路 (1{L > s})_{s ≤ a} を通してしか読まない**(観測はすべて時刻 ≤ a の
世界の関数であり、寿命は動力学に「生存中か否か」としてのみ入るため)。
指数分布は σ(min(L, s₀)) 型の条件付けに対し完全に無記憶(生存事象上でこの
σ-加法族は自明)。ゆえに時刻 a の情報の下で、{L^{our}_j}(そもそも未読の新鮮
コイン)と {R_j}(各候補の残余)は**共同独立な Exp(T_s)** であり、
P(A_j) = 1 − e^{−(t*−a_j)/T_s} ≤ 1 − β、β := e^{−T_g/T_s}。

*観察3(到着後の干渉は救済のみ)*: a 以降の rogue 活動は j への追加到着しか
生まず、追加到着は「生存中なら空振り/死亡なら再マーク」— **失格を作る経路がない**。
ゆえに観察1の包含は後続干渉で破れない。

*結論*: Σ_j Q̄_j ≤ Σ_j 1_{A_j} は(条件付きで)独立 Bernoulli(1−β) 和に
確率支配される。候補数 n ~ Poisson(μ/2)(開示控除後の新鮮 PPP+新鮮対コイン)、
N_h := ⌈βμ/8⌉ と取れば Chernoff により
P(開ビット = 1 | 𝒢_{i−1}) ≥ 1 − e^{−cμ} =: 1 − ε(m₁) → 1。∎

**なぜ非単調性の三重奏に阻まれないか**: 全過程の単調比較(v1 の間引き、censored
比較)を一切使わない。「失格の必要条件が私有コイン1個に局在する」ことと
「そのコインが条件付けで読まれていない」ことだけを使う。マークが決して
他者を殺さない(排除なし)というモデルの付加性が、失格側の一方向性
(干渉は救済のみ)を与える。
