# Phase R 文献地図(セッション1、2026-08-15 — 調査エージェント完全版は本文書末尾参照)

## 結論(照合の要旨)

**対象モデルは実在する空白領域にある**:
「Grimmett–Li(Brownian snails with removal — 連続空間+半径接触+Exp除去、ただし運動が
ブラウン運動)と Poisson 円柱パーコレーション(時空静的化、ただし方向測度が等方)の交点」。
弾道運動粒子上の感染・接触過程の厳密理論(生存相転移・前線速度・形状定理)は**存在しない**。

## 主張ラベル(既知/新規)

- **定理 A(絶滅 m<1)**: 手法は標準(第一モーメント+Mecke)、**モデルへの適用は新規**。
  最近縁: Grimmett–Li の delayed diffusion α_c ∈ (0,∞)(運動がブラウン)
- **定理 B(静的=ボンド希釈RGG)**: 対象は既知級(Penrose、Lichev+22 が希釈RGGを扱う)。
  **本モデルの静的極限としての同定が内容**(それ自体は軽い)
- **C2(生存)**: 弾道版は**未解決**。手法の前例は豊富(KS 多スケール、Dauvergne–Sly 結合、
  LSS 優越、HUVV 繰り込み)— C2 のブロック戦略は正当
- **C4(速度単調性)**: **近縁モデルでも公然の未解決問題**
  (KS: ジャンプ率単調性 open / Linker–Remenik: 環境速度 v の λ_c 単調性を明示的 open と記載)。
  方向は設定依存(希釈格子では運動が助け、スケールフリー網では害する)— 一般定理なし。
  **本モデルでの解決は価値が高い**
- **C5(交叉)**: 静的類似に Franceschetti+05 の squishing&squashing 定理
  (平均次数固定で「間引き+範囲拡大」はパーコレーションを容易にする — 単調性の厳密定理!)。
  **証明アイデア: 運動の寿命平均接触核はカプセル型 spread-out — Franceschetti 型
  再配置不等式との接続を試みる価値あり**(C4 の弱形の別経路)
- **C6(前線)**: KS 2008 形状定理(等ジャンプ率・拡散)/ Dauvergne–Sly(異速度・線形成長)。
  弾道版・非有界速度の超線形は**未知**。E5 の加速 1.34 は新規現象の候補
- **規約依存性(進入駆動 vs 滞在時間)**: 物理数値に強い前例
  (Peruani–Sibona 2008: 暴露時間×接触率の競合 / Rodríguez+19: **最適速度 v* の存在 =
  非単調の明示例、ただし別規約・非厳密)。E4 の単調性と矛盾しない(規約が異なる)—
  「規約が単調性を決める」という定式化自体が層3の定理候補
- **時空描像の先例**: Hyytiä–Ott 2012(DTN の傾き円柱・有向連続体パーコレーション、
  2+1次元・数値・非厳密)— 引用必須の工学先行。厳密化は空白のまま

## 使える既知の道具(C2 に向けて)

- 数値基準: 連続体パーコレーション臨界 η_c ≈ 0.3419(臨界平均次数 ≈ 2.735)
- LSS(Liggett–Schonmann–Stacey)有限レンジ従属→独立優越
- KS 2006 の「多スケール+有向パーコレーション比較」の設計図
- Baldasso–Stauffer 2023(回復付きの局所生存・高密度生存)の構成
