## 定理(C2・最終形)

ν を等方、速さ殻 S = {w : |w| ∈ [w₁, 2w₁]}(w₁ > 0)の質量 q = ν(S) > 0 とする。
単位は R = 1 に取る。定数 C₀ = C₀(τ/T_s) < ∞ が存在し、
**m₁ := p · ρq · π w₁ T_s > C₀ ならば、過程(再マーク禁止版、したがって元の過程も)は
正確率で生存する。**

## パラメータの固定

- 錐: e₊ = +e_x。u₁ := w₁/2、u₂ := 2w₁。
  D_± := {w ∈ S : w_x ∈ [u₁, u₂], sign(w_y) = ±, |w_⊥|/w_x ≤ 1}(w_⊥ = (w_y, w_z))。
  等方性より ν(D_±) ≥ c_D q(c_D > 0 は普遍定数)。
- 世代: T_a := min(T_s, τ) 型の細目を避け、T_g := 4(τ + T_s)、T_a := T_s。
- 格子: 時刻 t_k = kT_g。x ドリフト X_k := k·ū T_g(ū := (u₁+u₂)/2 = 5w₁/4)。
  y 間隔 ℓ_y := u₂T_g。箱 B_{n,k} := [X_k − a, X_k + a] × [nℓ_y − a, nℓ_y + a] × [−a, a]、
  a := u₁T_g/8。サイト (n,k)、n+k 偶数。
- 群れサイズ N_h(m₁ とともに選ぶ、後述)。

## 補題 1(幾何)

∃ c_geo = c_geo(普遍) > 0: 任意の y ∈ B_{n,k} ⊕ B(u₂T_a + 1)、任意の α ∈ [t_k, t_k+T_a]
に対し、集合 A_±(y, α) := {w ∈ D_± : y + w(t_{k+1} − α) ∈ B_{n±1, k+1}} は
ν(A_±) ≥ c_geo q を満たす。

*証明*: 必要変位は Δx = ūT_g + O(a + u₂T_a + 1)、Δy = ±ℓ_y + O(同)、残時間
t_{k+1} − α = T_g(1 − O(1/4))。必要速度 w* = Δ/(残時間) は w*_x ∈ [u₁, u₂] の内部、
|w*_y|/w*_x ≤ 1 の内部に O(1/8) の余裕を持って入る(a, T_a, ℓ_y の選定がこの余裕の
ためにある)。B_{n±1,k+1} は一辺 2a の箱なので、許容 w の集合は半径 ≳ a/T_g = u₁/8 の
速度球を含み、その ν 測度は等方性と殻の正質量から ≥ c_geo q。∎(定数の機械的検証は付録)

## 補題 2(流束 Poisson)

速度 V₀ ∈ S で運動する源に対し、「速度が可測集合 A ⊂ S に属する殻粒子の、
時間窓 [s, s+T] における B(源, 1) への新規進入」は、時刻順に強度
λ(A) = ρq ∫_A π |V₀ − w| ν̂(dw)(ν̂ = ν(·|S))の Poisson 過程をなし、
異なる源・重ならない (x₀,v) 制限集合に対しては独立である。
さらに w ∈ D_± と V₀ ∈ S に対し |V₀ − w| ≥ 0 の平均は
∫_{A} |V₀−w| ν̂(dw) ≥ c_rel w₁ ν̂(A)(c_rel > 0 普遍)。

*証明*: 写像定理(定理 A/C6a で審査済みのカプセル計算と同一)。相対速さの下界:
D_± は直径 ≳ w₁ の速度領域であり、任意の固定 V₀ からの平均距離は ≥ c_rel w₁。∎

## 補題 3(一世代中継)

サイト (n,k) に「良い親」P₀(マーク済み・生存・位置 ∈ B_{n,k}・速度 ∈ S、
残余寿命 ≥ T_a — 無記憶性より確率 e^{−1} で成立)が居るとする。
このとき、P₀ の [t_k, t_k+T_a] の新規進入のうち、速度 ∈ A_±・コイン成功・
マーク後 t_{k+1} まで生存・の子の数 N_± は、それぞれ独立に
Poisson(μ) 変数を確率支配し、μ ≥ c₃ · e^{−T_g/T_s} · p ρq π w₁ T_a ≥ c₄(τ/T_s) · m₁。

*証明*: 補題 1 の A_± は進入時刻・位置に一様に測度下界を持つので、補題 2 の
Poisson 過程を ν̂(A_±) ≥ c_geo q で間引く。コイン p は独立標識、
子の生存は独立 Exp: 期間 ≤ t_{k+1} − (α+τ) ≤ T_g で確率 ≥ e^{−T_g/T_s}。
T_g = 4(τ+T_s) より e^{−T_g/T_s} ≥ e^{−4(1+τ/T_s)} =: c(τ/T_s)。∎

**注(子の資格)**: 成功した子は t_{k+1} に B_{n±1,k+1} に居り(補題1の定義)、
速度 ∈ D_± ⊂ S、マーク済み・生存 — 次世代の「良い親候補」の資格を満たす。

## 補題 4(私有窓と新鮮性)

サイト (n,k) の**窓** W_{n,k} := (時空) B_{n,k} ⊕ B(u₂T_g + 2) × [t_k, t_{k+1}] に対応する
(x₀, v) 集合(この窓に軌道が交わる殻粒子の初期条件全体)。構成が参照する乱数は
(i) W_{n,k} 内の PPP 制限、(ii) 親群れの残余寿命(t_k で無記憶更新)、
(iii) 窓内ペアのコイン、のみである。

(a) **有限レンジ**: 窓 W_{n,k} と W_{n',k'} は |n−n'| > M₁ または |k−k'| > M₂ なら
(x₀,v) 空間で交わらない。M₁, M₂ は普遍定数(ドリフト設計: 全構成粒子の x 速度
∈ [u₁, u₂] であり、窓の x 幅 (≤ 2u₂T_g+4) をドリフト差 (≥ u₁T_g) が有限世代で
追い抜くため。M₂ ≤ ⌈(2u₂+5)/u₁⌉ ≤ 9)。

(b) **探索済み集合の摂動性**: 過去の全サイトが「使用」した粒子集合(親カプセルへの
進入者)は、各サイトあたり (x₀,v) 測度 ≤ ρq(V_1 + π u₂·2w₁... ) ·付録定数 ≤ c₅ρq
の薄いカプセル和に含まれる。依存レンジ内のサイト数は ≤ (2M₁+1)(M₂+1) なので、
補題 3 の強度 μ から差し引かれる最大量は c₆ρq ≤ μ/2
(**m₁ > C₀ の C₀ をこの比較が成り立つよう選ぶ**)。
ゆえに条件付きでも N_± は Poisson(μ/2) を支配する。

*証明*: (a) は算術。(b): 使用済み粒子は「どこかの親の半径1カプセル進入者」であり、
カプセルの (x₀,v) 測度は補題 2 の強度×窓長で押さえられる。除去は PPP の制限性より
「残りは依然 PPP」であり、強度の差し引きだけが効く。∎

## 定理の証明(組み立て)

サイト事象 G_{n,k} := 「t_k に B_{n,k} 内に資格粒子(マーク済・生存・速度 ∈ S)が
≥ N_h 個」。初期サイト (0,0): 種の近傍で m₁ 大なら種自身の初期中継で N_h 個の
資格粒子を作れる(補題 3 を1回使う: 確率 ≥ 1 − ε₀ > 0 で着火 — 正確率で良い)。

G_{n,k} の下で: 良い親(残余寿命 ≥ T_a)の数は Binomial(N_h, e^{−1})、
≥ N_h/4 が確率 ≥ 1 − e^{−cN_h}。**最初の良い親 P\*** のみを使い(他は捨てる —
付加的単調性)、補題 3+4 より N_± ≥ Poisson(μ/2) 独立(± は排反な速度錐)。
μ/2 ≥ c₄m₁/2 =: μ̄。N_h := ⌈μ̄/2⌉ と選ぶと、
P(N_± ≥ N_h) ≥ 1 − e^{−μ̄/8}(Chernoff)。
よって P(G_{n±1,k+1} | ℱ_k, G_{n,k}) ≥ 1 − ε(m₁)、ε(m₁) → 0(m₁ → ∞)、
依存は補題 4(a) の有限レンジ。

Liggett–Schonmann–Stacey により、この (M₁, M₂)-従属方向付きサイト場は
ε 十分小で独立 Bernoulli(1−δ) 場を確率支配し、δ < δ_c^{OP} で方向付き
パーコレーションが超臨界 ⇒ 無限系列の G が正確率で発火 ⇒ 各サイトに
マーク生存粒子が存在し続ける ⇒ 生存。∎
