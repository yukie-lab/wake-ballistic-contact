## 補題X(V-結合版 — 審査役5 §2(b) の修復を全文採用)

**準備**: 𝒢_{i−1} の下で、候補集合・進入時刻・到着時刻 a_j・c_j := t*−a_j は
(PPP 配置, 速度, 対コイン)のみの決定的関数(弾道性+P* の被覆保証の 𝒢 可測性)。
**寿命コインに依存しない。**

**V-結合**: 候補スロット j ごとに事前の i.i.d. V_j 〜 Exp(T_s) を割り当てる。
到着 a_j における支配クロック(場合 (i)(ii): 新鮮コイン / 場合 (iii): 現行 episode の
a_j 超過分 — 進行的開示によりいずれも a_j 時点で未消費)を V_j で実現する。

**経路ごとの包含(観察1の真の役割)**: すべての実現経路で Q̄_j ⊆ {V_j < c_j}
(場合分けは包含の証明にのみ使い、**条件付けには使わない** — これが v3 の

場合割当を歪めるが、包含 Q̄_j ⊆ {V_j < c_j} は経路ごとに成立し続ける)。

**独立性**: {V_j < c_j} は c_j がコイン非依存ゆえ、コイン非依存データの条件付きで
真に独立 Bernoulli(≤ 1−β)。⇒ Σ Q̄_j ≼ 独立 Bernoulli 和、Chernoff で
P(開ビット | 𝒢_{i−1}) ≥ 1 − e^{−c(β)μ}(**c は β = τ/T_s 依存と明記**)。
