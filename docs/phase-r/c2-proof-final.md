## 0. 定理

**定理 C2**: ν は等方、殻 S = {w : |w| ∈ [w₁, 2w₁]} の質量 q := ν(S) > 0、
S 上 Lebesgue に関し有界密度で**相対密度比** Λ̃ := (S 上の密度上界)/(q/vol(S)) ≤ 4
(例: Maxwell 型ガウスは典型殻で Λ̃ ≈ 2.4)。R = 1 に正規化し、
**混合数** K_mix := w₁T_s ≥ K₀ = 20 とする。このとき定数 C₀ = C₀(τ/T_s) < ∞ が存在し、
m₁ := p·ρq·πw₁T_s > C₀ ならば完全モデル(進入駆動・撃ちっ放し・対一回・再マーク許可・
遅延 τ・寿命 Exp(T_s))は正確率で生存する。

**一般 Λ̃ 条項**: 任意の Λ̃ < ∞ に対し K₀(Λ̃) < ∞ が存在し(橋の控除側は漸近 K₀⁻²
減衰・受理側は単調増加 — §5 の認証走査表)、C₀ = C₀(τ/T_s, K₀(Λ̃))。
機械認証値: K₀ = 20 で Λ̃ ≤ 7.8、K₀ = 24 で Λ̃ ≤ 12.9(v6 表)。
**開放**: 純等方(密度仮定なし)は予想として分離。

## 1. パラメータと格子

すべて R = 1、時間は T_s 単位。進入窓 **T_a := T_s/32**、世代時間 **T_g := 64(τ+T_s)**。

- **副殻鳩ノ巣**: [w₁, 2w₁] を等幅200分割し、質量最大の副殻を I*(質量 ≥ q/200、
  帯半幅 I_h ≤ w̄/400)、w̄ := I* の中央値とする。
- **照準定数**: ū_x := w̄/√(17/16)。理想必要速度 (ū_x, ±ū_x/4, 0) のノルムは
  **厳密に w̄ = I* 中心**(√(1+1/16) の相殺 — 照準は定義により厳密で、
  残差はすべて §2 の機械検証の摂動勘定に内包される)。
- **格子**: 箱幅 a := ū_x T_g/32、コア半幅 a/2、y トラック間隔 ℓ_y := 8a、z ≡ 0。
  サイト (n,k)(n+k 偶数)の2次元方向付き格子。**混成アンカー**: y,z は大域格子、
  x は親相対(ドリフト吸収)、標的は Λ = (a/8)ℤ³ に丸め(誤差 ≤ a/16 成分)。
- **錐**: D_± := {w : w_x/|w| ≥ 0.8, w_y/w_x ∈ ±[1/8, 1/2]}(z 成分は窓が拘束)。
- **親カバー**: 構成に登場する親速度は中心 (ū_x, ±ū_x/4, 0) の ±0.05w̄ 箱に含まれる
  (次世代親 = 受理候補の速度窓がカバー箱に含まれることは機械検査 cover ✓)。
- **着地窓**: 進入時刻 t_k+s の候補が世代末 t_{k+1} に標的コアへ入る速度窓は
  w_c(摂動実現の必要速度)⊕ [−h₀, h₀]³、h₀ := (a/2)/(T_g−s)。

## 2. 補題1(幾何 — 機械認証の契約)

**主張**: K_mix ≥ 20 の全摂動(親位置 ∈ コア+丸め、親速度 ∈ カバー箱、進入オフセット
|e| ≤ R、掃引 s ∈ [0,T_a]、丸め、枝 ±)に対し、
margin := h₀ − dev − I_h − lip ≥ s* = 0.0048w̄(τ=0; τ=1: 0.0054、τ=3: 0.0056)、
かつ窓箱は D_± と親カバーに含まれる。
dev は必要速度ノルムの w̄ からの偏差の厳密上界、lip は s-格子セルの Lipschitz 罰則。

**証明**: 機械検証(geo_verify.py v6)。区間演算 — 各摂動を成分区間で表し、
ノルムの min/max を閉形式(min: 各成分の 0 への距離の平方和、max: 端点最大の平方和)で
厳密評価。s は 4096 分割格子+セル内 Lipschitz(|dw_req/ds| ≤ (sup|v_p|+sup|w_req|)/
(T_g−T_a)、摂動込み sup)、h₀ はセル左端採用(h₀ は s 増加関数 — 保守側)。∎

**受理パッチ(消去形)**: 補題1の margin ≥ s* の下で、
U := {u ∈ S² : angle(u, w_c/|w_c|) ≤ θ*}、θ* := s*/(1.05w̄) と置くと、
任意の u ∈ U・r ∈ I* に対し |r·u − w_c|_∞ ≤ |r−|w_c|| + |w_c||u−u_c|
≤ (I_h + dev) + 1.05w̄θ* ≤ h₀(ℓ∞ ≤ ℓ₂)。ゆえに**パッチ U × I* 帯の全体が着地窓に
含まれる**。等方性の分解 ν̂ = (動径質量)×(一様角度)により
**ν̂(受理) ≥ (1/200)·(1−cos θ*)/2**。パッチの錐包含は窓箱の区間検査で担保。

## 3. 補題2(開示カプセルの同定 — 控除管長 = T_a の根拠)

**主張**: 構成が乱数場について読む情報は、各サイトの窓内進入カプセル
𝒞 = {(x₀,v) : inf T_{P*,·} ∈ [t_k, t_k+T_a]}、その対コイン、追跡判定
({L>s} 型指示関数のみ・観測打切 M = ⌈2μ⌉ 個)、私有コインに限る。

**証明**: (i) 等速直線運動では対の接触集合は単一区間なので、窓内進入 = 初回接触 =
対 (P*, j) はその瞬間まで未消費。**対一回は絶対規約**(順序対は生涯一度 —
再マークは対を再開しない)。窓内進入者への試行は窓内で確定発火し、構成は結果のみ読む。
(ii) 窓外の進入は構成の σ-加法族に一切現れない。力学はそこで別の順序対を消費し
マーク状態を変えうるが、(a) 新サイトの対の新規性に影響せず、(b) 未知マーク状態は
補題Xの場合分けが吸収する(干渉は救済のみ)。(iii) 窓は全世代一様 T_a(種も同じ)。∎

**帰結**: 控除管の線分長は |v−v_P|T_a — 「開示の幾何」であって「力学の露出」ではない。
再マークによる Exp(T_s) 裾の露出延長は開示側に生じない(力学的接触は補題Xの管轄)。

**候補の定義(受理反映2)**: サイトの候補は「**対 (P*, j) が新規**」の窓内進入者。
乱数の新鮮性は定義でなく §4 の控除が担保する — 過去サイトの窓内進入者(= 構成の
読取対象)は定義により §4 の bad 集合に一致し、控除で正確に落ちる
(読取 σ-加法族と控除対象の同一性が橋の要諦)。旧親・過去進入者がプールへ幾何的に
再登場する経路の明示的排除は不要。

## 4. 補題3(正規化橋 — 控除 ≤ ½·受理)

候補の速度標識は強度 dΦ(v) ∝ ρ·πR²·|v−v_P|·ν(dv)。受理(§2 パッチ)と控除を
**同一の正規化殻測度 ν̂ = ν/q** で比較する(相対速さ因子は §6 で上下から定数挟み)。
悪集合は力学・マーク状態に関して**無条件**の ν̂ で測る(幾何的には v を窓箱・子枝に
制限 — 8分岐の前提)。

**控除集合**: ギャップ j ≥ 1 の過去サイトとの開示交差は D(v) := Δ̃ − v·jT_g ∈
𝒦(v) := B(0,2R) ⊕ seg((v−v_P)T_a) ⊕ seg(−(v−v_{P′})T_a) を要する
(D(v) はアフィン・Jacobian (jT_g)³、ドリフトは平行移動で測度不変)。
同世代(j=0)兄弟は y 離隔 8a ≫ diam𝒦 で決定論的に交差なし。
種(第0世代)のカプセルは通常サイトとして算入。

**箱包 Steiner 上界(受理反映1 — sector 補題は廃止)**:
W := (V ⊖ P)·T_a は箱(成分区間差)。固定 v のセグメント seg[0, x](x ∈ W)の
v-合併は conv({0}∪W) ⊆ 成分区間包 H(凸性で1行)。ゆえに
∪_v 𝒦(v) ⊆ B(0,2R) ⊕ H₁ ⊕ (−H₂) は箱(辺 c = 辺和)⊕ 球であり、体積は厳密閉形式
vol = Πc + 2(Σᵢ<ⱼ cᵢcⱼ)r + π(Σcᵢ)r² + (4π/3)r³(r = 2R;
辺項 = 12辺 × 外二面角 π/2)。diam ≤ 4R + √(Σcᵢ²)。
共通 v の相関無視は上位集合被覆(∪[A(v)⊕B(v)] ⊆ (∪A)⊕(∪B))で保守側。
正当性は「新包 ⊇ 真の合併」の直接論証による(スポット審査済み)。

**サイト数補題**: ギャップ j の交差には Δ̃ ∈ jT_g·(v窓) ⊕ 𝒦 が必要 —
位置窓の径 ≈ j·a√3 + diam𝒦。y トラック間隔 8a で
n_j ≤ (√3/8)j + 1 + diam𝒦/(8a)。z は単一トラック(z ≡ 0 の2次元格子)、
x はギャップ j が世代を一意に定めるため、多重度は y のみ。
Σ_j n_j/j³ = (√3/8)ζ(2) + (1 + diam𝒦/8a)ζ(3) ≈ 1.57。

**橋の不等式(機械認証)**: ν̂(∪bad) ≤ Λ̃·[vol(𝒦)·Σ n_j/j³ / T_g³]/vol(S)、
vol(S) = (28π/3)w₁³。w̄ ∈ [w₁, 2w₁] はサイドごと最悪(控除分子 w̄ = 2w₁ /
幾何 slack w̄ = w₁)で分離評価。**認証: K₀ = 20, T_a = T_s/32 で
Λ̃·ν̂(bad) ≤ ½·ν̂(受理) が全 τ で成立** — τ=0(最悪): bad(Λ̃=1) = 1.69×10⁻⁹ vs
受理 2.64×10⁻⁸(Λ̃_max = 7.82 ≥ 4); τ=1: 77.5; τ=3: 684。
中間 τ は控除の τ 単調減(T_g³ 増・他項非増)+受理の τ 単調増(slack 増)で被覆。

## 6. 構成と補題X(V-結合)

**サイト事象 G_{n,k}**: t_k に箱 B_{n,k} のコアに資格粒子(マーク済み・生存・
速度 ∈ 親カバー箱)が ≥ N_h 個、かつうち ≥ 1 個の残余寿命 ≥ T_g(**被覆条項** —
無記憶性より各粒子が確率 β := e^{−T_g/T_s} で充足。エポック間の全時刻で
マーク生存集合が非空であることを保証する)。

**一世代中継**: 良い親 P*(被覆条項の粒子 — 残余 ≥ T_g ⊃ 窓)の窓内進入者のうち、
対新規(§3)・速度 ∈ 受理パッチ×I*(§2)・対コイン成功(p)・到着(遅延 τ)後
t_{k+1} まで生存、の子が標的コアに着地する(§2 の窓の定義)。

**流束下界(同枝補正込み)**: 反対枝の子は |v−v_P| ≥ 0.4w̄。同枝の子はパッチから
v_P 中心・半径 θ*w̄/2 の球を控除した残り(キャップ立体角比 ≥ 1/4)で
|v−v_P| ≥ θ*w̄/2 > 0。いずれも係数は K₀ 固定下の設計定数のみの関数で
m₁・ρ に依存しない(循環なし — サイクル11監査確認)。ゆえに候補数は
**Poisson(μ)、μ ≥ c₄(τ/T_s)·m₁/32** を確率支配(橋 §4 により控除後も ≥ μ/2)。

**補題X(私有コイン独立性 — 資格下界)**: 𝒢 を構成の全開示(カプセル PPP・対コイン・
追跡判定)とする。対新規の候補 j への成功到着(時刻 α)について
P(j が t* にマーク済み生存 | 𝒢, 到着) ≥ (1−δ)e^{−(t*−α)/T_s}。

*証明*(v3 で確定、サイクル5〜8で審査済み):
- **観察1(失敗の必要条件は私有コイン)**: 失格 Q̄_j は到着時の j の状態3場合すべてで
  「j の私有コイン1個の不足」を含意する — (i) 未マーク → 我々がマーク: 失格 ⇒
  新鮮寿命 L_j < t*−α。(ii) マーク済み死亡 → **再マーク許可**により再マーク: (i) と同じ。
  (iii) 生存中 → 空振りだが資格保持中: 失格 ⇒ 現行残余 R_j < t*−α。
  いずれも Q̄_j ⊆ A_j := {私有コイン不足}。
- **観察2(共同独立性)**: 時刻 α までの全条件付けは各粒子の寿命を
  **指示関数経路 (1{L>s})_{s≤α} を通してしか読まない**。指数分布は
  σ(min(L,s₀)) 型条件付けに完全無記憶なので、{L_j}(未読の新鮮コイン)と
  {R_j}(残余)は条件付きでも共同独立な Exp(T_s)。P(A_j) ≤ 1 − β。
- **観察3(到着後干渉は救済のみ)**: α 以降の rogue 活動は j への追加到着しか生まず、
  追加到着は「生存中なら空振り/死亡なら再マーク」— 失格を作る経路がない。
  ゆえに観察1の包含は後続干渉で破れない。∎

**注**: 全過程の単調比較(間引き・censored 比較)は一切使わない。マークが他者を
決して殺さない付加性が、失格側の一方向性を与える — 非単調性の三重奏に阻まれない理由。

**開ビット**: 追跡中継が届けた子 ≥ N_h(出自不問の資格粒子は照会しない — 可測性)。
Σ_j Q̄_j ≤ Σ_j 1_{A_j} は独立 Bernoulli(1−β) 和に確率支配され、
N_h := ⌈βμ/16⌉ と取れば Chernoff により
P(開 | 𝒢) ≥ 1 − e^{−cμ} =: 1 − ε(m₁) → 1(m₁ → ∞)。

## 7. 組み立て

逐次(幅優先)条件付けで P(開_i | 開_{<i}) ≥ 1−ε の一様下界(タワー性 — 全開示 𝒢 での
下界から従う)。ゆえに開ビット列は iid Bernoulli(1−ε) の方向付きサイト
パーコレーションを確率支配する。ε(m₁) → 0 なので m₁ > C₀ で 1−ε > 3/4 ≥
p_c(2次元方向付きサイト格子; Liggett 1995)。
【裁定ログ#10 修正2 チェックリスト: Liggett の上界が証明された格子と本構成の
(n,k)-格子(n+k 偶、子 = (n±1, k+1))の隣接構造の一致をドラフトで明示確認】
超臨界 ⇒ 無限開系列が正確率で存在。被覆条項により各エポック間もマーク生存粒子が
存在 ⇒ 全時刻でマーク生存集合非空 ⇒ 生存。

**着火**: 種(任意速度)から数世代のブートストラップで第1サイトに N_h 群れを
正確率で形成(生存は正確率主張なので十分)。

**定数の一様性**: m₁ の上界はどこにも使わない — 被覆条項・Chernoff・観測打切
M = ⌈2μ⌉ は μ 増加で改善または不変。費用項の (K_mix, τ/T_s) 非増加性は項別明示式。
C₀ は {c₄, β, 橋の 1/2, Chernoff 定数} から明示的に組める(定量化は開放問題 —
凍結リスト「C₀ の明示定数化」)。
