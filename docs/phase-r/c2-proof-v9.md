## 定理(v9)

ν は等方、殻 S = {|w| ∈ [w₁, 2w₁]} の質量 q > 0、かつ S 上 Lebesgue に関し有界密度で
**相対密度比 Λ̃ := (S 上の密度上界)/(q/vol(S)) ≤ 4**(ガウス系は Λ̃ ≈ 2.4 で充足)。
R = 1、混合数 K_mix := w₁T_s ≥ **K₀ = 20**。このとき C₀ = C₀(τ/T_s) が存在し、
m₁ = pρqπw₁T_s > C₀ ⇒ 完全モデル(再マーク許可)は正確率で生存する。

**一般 Λ̃ 条項**: 任意の Λ̃ < ∞ に対し K₀ = K₀(Λ̃) < ∞ が存在する(橋の控除側は
漸近的に K₀⁻² で減衰、受理側は K₀ 単調増加 — 検証器 v5 の走査表; K₀(4) = 20、
K₀ = 24 で Λ̃ ≤ 6.9)。純等方(密度仮定なし)は予想として分離(変更なし)。

## 修復1: 橋補題(サイクル10 残項目1 — 重大)

**設定**: 候補は親カプセルへの窓内進入であり、その速度標識は強度
dΦ(v) ∝ ρ·πR²·|v−v_P|·ν(dv) に従う。受理集合(パッチ)と控除集合(悪スラブ)を
**同一の正規化殻測度 ν̂ = ν(·)/q** で測り、相対速さ因子は上下から定数で挟む

|r·u − w_c|_∞ ≤ |r − |w_c|| + |w_c|·|u − u_c| ≤ (I_h + dev) + 1.05w̄·θ* ≤ h₀
(ℓ∞ ≤ ℓ₂ を使用)。ゆえに **パッチ × I* 帯の全体が窓に含まれ**、
ν̂(受理) ≥ (1/200)·(1−cos θ*)/2。
帯の動径全被覆はこの不等式そのものが与える(動径再鳩ノ巣は不要 — v8 の主張の
正確な形。照準は ū_x := w̄/√(17/16) の定義により **|理想 w_c| = w̄ = I* 中心が厳密**に

パッチが錐 D_± に含まれることは窓箱の区間検査で確認(検証器 cone ✓)。

**控除側**: 過去サイト(ギャップ j)との開示交差は D(v) := Δ̃ − v·jT_g ∈ 𝒦 を要し、
𝒦 = B(0,2R) ⊕ seg((v−v_P)T_a) ⊕ seg(−(v−v_{P′})T_a)。v は窓包(区間包 hull)を、

- **体積(厳密 Steiner)**: 平行四辺形 ⊕ 球 B(r) の体積 = 2L₁L₂sinθ·r + πr²(L₁+L₂)

  切替える(組合せ8通りの最大を採用 — 摂動込み・機械計算。残項目5への応答)
- **サイト数**: 位置窓の径 j·a√3 + diam(𝒦)、y トラック間隔 8a ⇒
  n_j ≤ (√3/8)j + 1 + diam(𝒦)/(8a)。**z は単一トラック**(全サイトの z アンカー ≡ 0、
  比較格子は (n,k) の2次元方向付きサイト格子)であり z 多重度は生じない。

**橋の認証(検証器 v5)**: ν̂(∪bad)·Λ̃ ≤ ½·ν̂(受理) が **K₀ = 20, T_a = T_s/32,

## 修復2: 開示カプセル同定補題(サイクル10 残項目2 — 重大)

**主張**: 構成が乱数場について読む情報は、各サイトの**窓内進入カプセル**
𝒞 = {(x₀,v) : inf T_{P*,·} ∈ [t_k, t_k + T_a]}(とその対コイン・追跡判定・私有コイン)
に限られる。ゆえに控除管の長さは T_a であり、露出延長(T_a + O(T_s))は生じない。

*証明*: (i) 等速直線運動では接触集合 {t : |x_j(t) − x_{P*}(t)| ≤ R} は
**単一区間**(相対速度一定)。ゆえに「窓内進入」= 初回接触が窓内 = 対 (P*, j) は
その瞬間まで未消費であり、**対一回規約は絶対**(§0: 順序対は生涯一度だけ試行。
再マークは対の再開を許さない — 規約であって推論ではない)。窓内進入者への試行は
窓内で確定的に発火し、構成はその結果のみ読む。
(ii) 窓外(t > t_k + T_a)の進入は構成の観測対象外 — 構成の σ-加法族に**一切**現れない。
力学はそこで対を消費しうるが、それは(a) 別の順序対であり新サイトの対 (P*_new, j) の
新規性に影響しない、(b) j のマーク状態を変えうるが、補題X(V-結合)の場合分け
(i)(ii)(iii) が未知のマーク状態を吸収し、到着後干渉は救済のみ(観察3)。
(iii) 全世代の窓は一様に T_a(構成は世代一様 — 第0世代の種カプセルも同じ窓)。∎

**帰結**: 𝒦 の線分長 |v−v_P|T_a は「開示の幾何」であって「力学の露出」ではない。
審査役の懸念(再マークによる Exp(T_s) 裾の露出延長)は開示側には生じない —
延長されうるのは力学的接触だけであり、それは補題Xの管轄で、控除の対象ではない。
