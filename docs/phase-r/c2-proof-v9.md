## 修復2: 開示カプセル同定補題(サイクル10 残項目2 — 重大)

**主張**: 構成が乱数場について読む情報は、各サイトの**窓内進入カプセル**
𝒞 = {(x₀,v) : inf T_{P*,·} ∈ [t_k, t_k + T_a]}(とその対コイン・追跡判定・私有コイン)
に限られる。ゆえに控除管の長さは T_a であり、露出延長(T_a + O(T_s))は生じない。

*証明*: (i) 等速直線運動では接触集合 {t : |x_j(t) − x_{P*}(t)| ≤ R} は
**単一区間**(相対速度一定)。ゆえに「窓内進入」= 初回接触が窓内 = 対 (P*, j) は
その瞬間まで未消費であり、**対一回規約は絶対**(§0: 順序対は生涯一度だけ試行。
再マークは対の再開を許さない — 規約であって推論ではない)。窓内進入者への試行は
窓内で確定的に発火し、構成はその結果のみ読む。
(ii) 窓外(t > t_k + T_a)の進入は構成の観測対象外 — 構成の σ-加法族に**一切**現れない。
力学はそこで対を消費しうるが、それは(a) 別の順序対であり新サイトの対 (P*_new, j) の
新規性に影響しない、(b) j のマーク状態を変えうるが、補題X(V-結合)の場合分け
(i)(ii)(iii) が未知のマーク状態を吸収し、到着後干渉は救済のみ(観察3)。
(iii) 全世代の窓は一様に T_a(構成は世代一様 — 第0世代の種カプセルも同じ窓)。∎

**帰結**: 𝒦 の線分長 |v−v_P|T_a は「開示の幾何」であって「力学の露出」ではない。
審査役の懸念(再マークによる Exp(T_s) 裾の露出延長)は開示側には生じない —
延長されうるのは力学的接触だけであり、それは補題Xの管轄で、控除の対象ではない。
