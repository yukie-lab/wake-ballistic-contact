## 混成アンカー(サイクル6 の構造的ギャップの解消)

- **y, z 座標: 大域アンカー** — 子ターゲット箱の y 中心 = n·ℓ_y、z 中心 = 0(固定格子)。
  親の y,z オフセットは「前世代コア着地 + 丸め」で ≤ core + a/8 に**非蓄積的に有界**。
  ⇒ **同世代サイトの y 分離は決定的**(2ℓ_y = 16a、箱幅 2a)— Δn=0 衝突は消滅
- **x 座標: 完全相対化** — 子ターゲット x 中心 = round_Λ(x_{P*} + ū_xT_g)。
  親 x オフセットの速度費用は厳密にゼロ(v1-v3 の致命傷の解消を維持)。
  x ドリフトは平均ゼロ雑音の蓄積(√世代)だが:
  (i) 同世代衝突は y アンカーが排除、

## 補題X(V-結合・打ち切り実現版 — サイクル6 §2 の形式化修正)

- **打ち切り実現**: 各候補スロット j の事前 i.i.d. V_j 〜 Exp(T_s) は
  **指示関数 {V_j ≥ c_j} のみ**を結合に使う(生存側では超過分を未実現のまま
  無記憶継続として残し、死亡側では完全開示)。同一エピソードが後世代で
  再スロット化される場合の二重結合を回避(well-defined 化)
- **上側開示の控除**: 被覆条項検査で不合格となった子(残余 < T_g の上側開示を
  負う粒子)は以後の候補プールから**明示的に控除**(祖先控除の j=1 項)。
  「死亡判定は過去エピソードのみ開示・無害」の適用範囲をこの控除で正確化
- 経路ごとの包含 Q̄_j ⊆ {V_j < c_j}(観察1)・c_j のコイン非依存性(弾道+
  被覆保証の 𝒢 可測性、下側開示は包含を自明化する方向で一様無害 —
  サイクル6 §2(b) 検証済み)・独立 Bernoulli 支配+Chernoff は v4 と同じ
