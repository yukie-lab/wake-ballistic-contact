## ブロッキング項目の解消: 平行管控除補題(決定的分離論法の全面置換)

**補題(平行管変位)**: 過去サイト σ'(世代ギャップ j ≥ 1)の開示集合と現サイトの
候補プールの (x₀,v) 交差を考える。固定速度 v に対し双方の集合は方向 v の平行管
(半径 R、長さ ≤ 2K_mix R + 2R)であり、交差には横変位 ≤ 2R かつ縦重なりが必要。
変位 D(v) = [箱位置差] − v·(jT_g) は v に線形(Jacobian (jT_g)³)なので、
**交差する v の測度 ≤ C·R²(K_mix R)/(jT_g)³**。プール速度窓の測度 (2h·…)³ ≈ (a/T_g)³
に対する割合は
  ≤ C′·K_mix·(R/(w̄T_g))³·(w̄T_g/a)³/j³ = C′′(τ/T_s)/j³(K_mix 依存も非増加)。
**箱位置差はドリフトを含むが、ドリフトは D(v) の平行移動であり測度不変** —
同アーム・異アーム・任意の分岐深さ g を区別なく一様に処理する
(v6 の決定的 x 分離論法は削除。g–j 混同はこの補題で無関係化)。
ギャップ j のサイト数は方向付き錐内で ≤ C(2j+1)。総控除割合
  Σ_j C(2j+1)·C′′/j³ < ∞、
定数は T_g = 64(τ+T_s)・K₀ = 6 の下で ≤ 1/2 に取れる(係数計算は付録、
条件付き下界の全履歴一様性はこの決定論的測度評価から従う)。
