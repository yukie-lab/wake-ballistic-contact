## 項目1の解消: 動径射影会計(サイクル7 §2 の全面書き直し)

被覆の締め所は **動径方向のみ**: 受理集合 A(コア狙いの速度箱、成分半幅
h := (a/2)/(t*−α))が薄殻 I* と錐に正測度で交わる十分条件は
||w_req| − w̄| + I*半幅 ≤ h(箱の動径到達 ≥ h は max|r̂_i| ≤ 1 より常に成立)。
各摂動 δ(位置空間)の寄与は速度シフト δ/(t*−α) の**動径射影**:
- 親 y オフセット(≤ a/2、アンカーで非蓄積): 射影率 |r̂_y| = w_y/|w| ≈ 0.24 → **0.24h**
- 親 z オフセット: |r̂_z| = w_z/|w| ≈ 0 → **≈ 0**(z 費用はほぼ消滅 — v5 の 2× は誤り)
- x 丸め(**Λ := (a/8)ℤ³ に変更**、誤差 ≤ a/16): 0.97 × (a/16)/(t*−α) ≈ **0.12h**
- 枝反転ドリフト(v4 欠落項・サイクル6検証済み係数): ベクトルは主に y 方向 →
  動径射影 0.24 × 0.0089w̄ ≈ **0.07h**
- 進入オフセット |e| ≤ R(方向任意 → 全射影): R/(T_g−T_s) ≤ **0.134h**(K₀=5 で縮小)
- I* 半幅(副殻200): w̄/400 ≈ **0.08h**
**動径合計 ≈ 0.64h < h(余裕 0.36h)**。スカラー和(v5 の誤り)は放棄。

**機械検証(証明級)**: geo_verify.py v2 — 摂動角点列挙(固定 s でアフィン ⇒
