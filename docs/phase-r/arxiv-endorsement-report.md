## 制度の要点

- エンドースメント要求は**カテゴリ単位**、エンドーサー資格は**ドメイン単位**
  (math.PR → math ドメイン、cond-mat.stat-mech → cond-mat ドメイン)【確認】
- 独立研究者(gmail・arXiv 論文なし)は自動エンドースメント実質不可 →
  既存著者への個別依頼ルートが前提【確認+推測】
- エンドーサー資格: 当該ドメインに「3か月前〜5年前」の投稿を一定数(具体数は
  非公開・依頼ページで個別表示)【確認】。6文字コードを依頼先に渡す方式【確認】
- エンドースメントは査読ではない(公式明記)【確認】
- 候補の在否は各論文アブストラクト頁下部
  「Which authors of this paper are endorsers?」で確認可能【確認】

## カテゴリ判定

**math.PR 主 + cond-mat.stat-mech 副が適切**。同種の定理証明型論文はほぼ math.PR 主
【API 観察で確認】。cond-mat 主はエンドーサー母集団が狭まり再分類リスクもある【推測】。

## エンドーサー候補(投稿実績は API 確認済み。**依頼送付は前田さんの裁定待ち**)

内容適合が最も高い群【推測】: Linker(動的ネットワーク上の接触過程)/
Valesin(接触過程の変種)/ Hilário(interchange 過程上の接触過程)/
Gracar(動的 Boolean モデル)/ Stauffer(動的パーコレーション上のスピン系)/
Broman(Poisson 円柱・感染系)。
次点: Durrett / Mountford / Vares(接触過程本流)、Penrose / Jahnel / Grimmett
(確率幾何・動く粒子系)、Sousi / Baldasso(移動粒子・感染)。
(全員が直近5年内に複数の math.PR 投稿を保持 — 資格充足はほぼ確実だが断定不可。
メールアドレス収集・連絡文面作成は行っていない。)

## 実務手順(独立研究者)

1. アカウント作成(gmail 可、ORCID 連携推奨)→ 2. math.PR 投稿開始で
エンドースメント要求発行・コード取得 → 3. 引用文献の著者からエンドーサー在否を確認 →
4. 依頼(**裁定後**。完成原稿+Zenodo DOI を添える)→ 5. AI 開示は付録B+
方法論記載で対応、参照文献の実在を全数検証 → 6. Zenodo 先行公開は障害にならない
【慣行・推測扱い】。
