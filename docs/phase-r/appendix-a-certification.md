## A.2 検証器の設計(証明との契約)

- **区間演算**: 全摂動(親位置・親速度・進入オフセット・丸め・掃引 s・枝 ±)を
  成分区間で表現し、ノルムの min/max を閉形式で厳密評価
  (min: Σ dist(0,[lo,hi])²、max: Σ max(lo²,hi²))。
- **s 格子+Lipschitz 罰則**: 4096 分割、|dw_req/ds| ≤ (sup|v_p|+sup|w_req|)/(T_g−T_a)
  (摂動込み sup)、h₀ はセル左端(増加関数ゆえ保守側)。
- **橋認証**: 受理 = (1/200)(1−cos θ*)/2(θ* = slack/1.05w̄、消去形パッチ補題)。
  控除 = 箱包 Steiner(Πc + 2Σcᵢcⱼ·r + πΣcᵢ·r² + (4π/3)r³、r=2R)×
  サイト数級数((√3/8)ζ(2) + (1+diam𝒦/8a)ζ(3))/ T_g³ / 殻体積。
  w̄ 両側最悪(分子 2w₁ / slack w₁)を分離採用。
- **保守性の方向**: すべての近似は上界(控除)/下界(受理)方向に単調。
  正当性は「箱包 ⊇ 真の合併 ∪𝒦」の直接論証(スポット審査済み — B.4)。

判定: **K₀=20, Λ̃ ≤ 4, T_a=T_s/32 で PASS(橋認証+幾何認証)** — 定理仮定

指摘どおり橋は閉じない — 台帳 B.4 参照)。中間 τ・中間 K₀ は単調性で被覆
(控除: T_g³ 増・他項非増 / 受理: slack 単調増 — 全走査表はログ参照)。
