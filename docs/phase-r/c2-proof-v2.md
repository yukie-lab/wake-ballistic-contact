**混合領域仮定**: K_mix := w₁T_s ≥ K₀(普遍定数)。

## 中核の新補題(干渉の無記憶性解消)

**補題 0(一様資格下界)**: 構成が粒子 j に時刻 a で成功到着(コイン成功+到着処理)を
行うとする。j のマーク履歴(構成外の rogue 連鎖による事前マーク・死亡を含む)が
いかなるものであっても、
P(j が t* := t_{k+1} にマーク済み生存 | 到着時刻 a、履歴の任意の実現) ≥ e^{−(t*−a)/T_s}。

*証明*: 到着時の j の状態は3通りで尽きる。
(i) 未マーク → 到着がマークし、寿命は新鮮な Exp(T_s): P(生存) = e^{−(t*−a)/T_s}。
(ii) マーク済み死亡 → **再マーク許可**により到着が再マークし、(i) と同じ。
(iii) マーク済み生存 → 到着は空振りだが j は資格保持中であり、
     指数寿命の**無記憶性**により残余寿命は Exp(T_s): P(生存) = e^{−(t*−a)/T_s}。
3 場合とも同一の下界。履歴への依存が消える。∎

**注(構造的双対)**: 再マークは絶滅側(定理 A)の第一モーメント勘定を壊す(A-1 ギャップ)
一方、生存側では干渉を消す救済者になる。v1 が要した「win-win 多スケール」は不要となる。

  質量最大の副殻 I*(質量 ≥ q/20)を選ぶ。w̄ := I* の中央値。
- 錐: D_± := {w : |w| ∈ I*, w_x/|w| ≥ 4/5, sign(w_y)=±, |w_y|/w_x ∈ [1/8, 1/2]}。
  等方性より ν(D_±) ≥ c_D q(c_D 普遍)。**連続世代の方向は ±交替し、
  相互角 ≥ θ₀(普遍)を持つ**(カプセル横断性に使用)。
- ドリフト: ū_x := w̄·(D_± の x 方向平均 ≈ 0.9w̄)。ℓ_y := ū_x T_g **/ 4**
  (v1 の誤りの修正: 必要速度 (ū_x, ±ℓ_y/T_g) ≈ w̄(0.9, ±0.22) は |w*| ∈ I* 内・
  比 0.25 ∈ [1/8,1/2] 内に O(1/20) 余裕で入る — 審査役の修正案どおり機械的に検証可能)

- **混合領域で全長さが整合**: a/T_g = ū_x/32 ≳ w₁、接触半径 1 ≤ w₁T_s/K₀ ≪ a。
  (v1 の次元問題の解消: K₀ を「1(=R)由来の全スラックが錐余裕の 1/10 以下」となる
  普遍定数に取る。)

## 構成(幅優先・逐次条件付け)

**サイト**: (n,k)、n+k 偶数。箱 B_{n,k}(x 中心 X_k = k·ū_xT_g、y 中心 nℓ_y)。
**サイト事象 G**: t_k に B 内に「資格粒子」(マーク済み・生存・速度 ∈ I* 帽 —
出自不問(rogue 歓迎: 補題 0 の (iii)))が ≥ N_h 個、
**かつ** うち ≥ 1 個は残余寿命 ≥ T_g(被覆条項 — τ > T_s の空白期間対策。
無記憶性より各資格粒子が確率 e^{−T_g/T_s} で満たす)。

**一世代中継**: 良い親 P*(残余 ≥ T_a、確率 e^{−1}・無記憶)の捕獲カプセル
([t_k, t_k+T_a] の新規進入)から:
1. 速度 ∈ A_±(補題1' — 修正幾何で ν(A_±) ≥ c_geo q、機械的検証)
2. **D-分離間引き**: 候補を相互距離 ≥ D := (log m₁)² 単位で間引く
   (カプセル長 w̄T_a ≫ N_h D は m₁ 大で成立)。目的: エポック内の候補間
   影響連鎖の遮断。非殻高速粒子経由の連鎖は Gauss 裾で
   P(影響) ≤ exp(−cD²/(T_g)²·σ⁻²…) → 0(補題: 速度 > D/T_g の粒子の局所期待数)
3. コイン成功(p)→ 到着 → **補題 0** で一様資格下界 e^{−T_g/T_s}
4. 候補数は Poisson(μ)、μ ≥ c₄(τ/T_s)·m₁(v1 と同形・修正幾何で正当化)

**開示の会計(カプセルのみ開示)**: 各サイトが開示するのは
(i) P* のカプセル進入者の (x₀,v)(質量 ~ m₁/p 個相当)、(ii) その対コイン、
(iii) P* の残余寿命判定と採用候補の資格判定(補題 0 型 — 判定は {L>s} 型のみで
将来の寿命情報を漏らさない)。
**新サイトの候補プールからの差引** = 過去開示カプセルとの (x₀,v) 交差のみ:
- 平行だが y に ℓ_y ≥ 4a ≫ 1 離れた管: 交差なし
- 連続世代(±交替で相互角 ≥ θ₀)の管: 交差体積 ≤ C/sinθ₀ = O(1) 個相当
- 近傍サイト数は有限(構成木の局所性)⇒ 差引合計 ≤ C'·ρq·R³·(サイト数) 個相当
- プール ~ ρq πR² w̄T_s 個相当。**比 ≤ C''·R/(w₁T_s) = C''/K_mix ≤ 1/2**(混合領域)
⇒ 差引後も μ/2 保証。**p 依存問題(v1 4b.2)は消滅**(プールと差引が同じ ρq 比例)。

**支配**: 逐次(幅優先)に P(G_next | これまでの全開示) ≥ 1−ε(m₁) の一様下界
⇒ iid Bernoulli(1−ε) の方向付きサイトパーコレーションを直接支配(LSS 不要 —
審査役ロードマップどおり)。ε(m₁) → 0 で超臨界 ⇒ 無限系列の G。
被覆条項により各エポック間も資格粒子が存在 ⇒ **全時刻でマーク生存集合非空** ⇒ 生存。

**着火**: 種(任意速度)から数世代のブートストラップ: 種の遭遇率は
λ_seed ≥ ρq πR² c w₁ > 0、m₁ 大で確率 ≥ δ₀ > 0 で第1箱に N_h 群れを形成
(正確率で十分 — 生存は正確率主張)。
