## 定理 A(絶滅・第一モーメント)【状態: **改訂版**証明あり(再マーク禁止版)/ 再マーク版は補題ギャップ1件】

> **改訂(セッション2・自己審査による)**: 初版の「m<1 ⇒ 絶滅」は誤り。
> 経路の隣接ステップ因子が速度を共有して相関するため(|v_{j−1}−v_j| と |v_j−v_{j+1}|)、
> スカラー m^k への因数分解は不当。正しくは転送核のスペクトル条件(下記)。
> E1 の数値(閾値 m≈1.0–1.3)はガウス殻で相関補正が小さいことと整合し影響なし。
> **自己審査が実誤りを検出した記録**(検証文化の実績4件目)。

**主張(改訂)**: 転送核 K(v, v′) := p·ρ·(V_R + πR² |v−v′| T_s) を ν 上の
積分作用素 (Kf)(v) = ∫ K(v,v′) f(v′) ν(dv′) とみなし、そのスペクトル半径を r(K) とする。
再マーク禁止版の M において **r(K) < 1 ならば** E[総マーク数] < ∞、したがって a.s. 絶滅。
**系 A′(有界速度)**: 速さ ≤ w_max なら m̄ := p·ρ·(V_R + 2πR² w_max T_s) ≥ sup-ノルム界で、
m̄ < 1 ⇒ 絶滅。**注**: 平均場値 m = p(deg+λT_s) は r(K) の下界(Jensen)であり、
m < 1 は絶滅の十分条件では**ない**(初版の誤り)。真の絶滅域は m ≤ r(K) < 1。

**証明**:
種を原点の追加点とする(Palm)。マーク事象は親試行の木をなす。深さ k のマーク点は
「時間順序つき開路」(i_0=種, i_1, …, i_k)に対応する: 各ステップで
(a) 順序対コイン U ≤ p、(b) 時刻列 t_1 ≤ … ≤ t_k が存在して t_j ∈ T_{i_{j-1} i_j} かつ
t_j ≤ t_{j-1} + τ + L_{j-1}(L は iid Exp(T_s):親は自分のマーク t_{j-1}+τ から
寿命 L_{j-1} の間だけ試行できる)。これはマーク成立の必要条件(緩和)である。

鍵の補題(**カプセル体積・厳密**): 速度 w の点が、時刻区間 [s, s+L] に源(位置 x、速度 v)
の半径 R 球と接触窓を交わらせる初期位置の集合は、半径 R のカプセル
(球 + 掃引円筒)であり、その体積はちょうど V_R + πR²|v−w|L。
ゆえに源1つ・寿命 L あたりの「使用可能ペア」の期待数は
ρ E_L[V_R + πR² E_w|v−w| L] = deg + λ T_s (源の速度 v で平均すれば E|v_rel|)。

相異なる k 点組への multivariate Mecke 公式で、位置積分はステップごとにカプセル体積を
与え(寿命 L_j で Exp 平均: E[L]=T_s)、速度積分が残る:
E[#深さ k の開路] ≤ ∫ ν(dv₀) (K^k 𝟙)(v₀) ≤ C_ν · r(K)^k (1+o(1))
(K は上記転送核。隣接因子は v_j を共有するためスカラー化できず、作用素冪で評価する)。
r(K) < 1 なら Σ_k が収束し E[総マーク数] < ∞。
マーク数有限+寿命有限 ⇒ 生存集合はいつか空。∎
(細部: (K^k 𝟙) の増大が r(K) で押さえられるための ν の可積分条件 — ガウスは
全モーメント有限で K はコンパクト正作用素、Krein–Rutman で r(K) は主固有値。審査対象。)

**ギャップ(再マーク許可版)**: 経路が同一点を(非連続に)再訪しうる。順序対は

## 定理 C6a(超線形前線)【状態: 証明あり(完全)】

**主張**: T_s = ∞、p > 0、ν の速さ分布の台が非有界(例: ガウス)なら、
マーク集合の原点からの最大距離 R(t) は a.s. R(t)/t → ∞。

**証明**: 任意の W > 0 を固定。速さ ∈ [W, W+1] の粒子クラスの強度は
ρ_W = ρ·ν(shell_W) > 0。種粒子 s₀ は永続的にマーク済み(T_s=∞)であり、
クラス W の粒子と率 λ_W = ρ_W πR² E[|v_{s₀} − w|] > 0 で新規遭遇する
(弾道ペアの遭遇は各ペア高々1回・ペアごと独立コイン p)。遭遇は s₀ の軌道に
沿ったカプセルへの Poisson 点の入射だから、成功伝播の総数は平均 p λ_W t の
Poisson 変数で t→∞ で a.s. 無限大。よってあるクラス W 粒子 j がいつか(時刻 t_W で)
マークされる。以後 |x_j(t)| = |x_j(t_W) + v_j (t−t_W)| ≥ W t (1−o(1))。
ゆえに liminf R(t)/t ≥ W。W は任意。∎

**注**: E5 の実測(ガウスで成長率比 1.34)はこの定理の有限時間の影。
CN19 の「前線は分布の裾の最速星が運ぶ」(𝒱 因子)の無限系版が定理になった。

## 定理 C2(生存 — セル・リレー構成)【状態: 証明スケッチ完成(厳密化可能な水準)/ 審査前】

**p · ρ πR² w₁ q² · T_s > C ならば正確率で生存する。**
(定理 A と合わせ、臨界面は2つの分枝型表式の間に挟まれる — **層1完結**。
命題 D と合わせ、**層3「十分速い運動は静的幾何が禁じる入植を可能にする」が定理になる**。)

**構成(証明の骨格)**:

*(0) 安全な間引き*: 粒子を速さ殻 [w₁,w₂] に間引く(過程は付加的単調 —
間引き版の生存 ⇒ 元の生存)。再マークも無視。以後 ν は殻上等方、強度 ρq。

*(1) 時空セル格子*: 世代時間 T_g := 2(τ + T_s)、箱幅 ℓ := w̄ T_g/2(w̄ = 殻平均速さ)。
サイト (n,k) ∈ ℤ×ℕ(n+k 偶数)に空間箱 B_n = [nℓ−ℓ/2, nℓ+ℓ/2]×[−ℓ/2,ℓ/2]²、
時刻 t_k = k T_g。サイト事象 G_{n,k}:「t_k に B_n 内に、殻速度のマーク生存粒子が存在」。

*(2) 1世代の中継補題*: G_{n,k} の親粒子 P₀ について(生存は t_k 時点で条件付け —
指数寿命の無記憶性より残余寿命は新鮮な Exp(T_s)):
- P₀ は [t_k, t_k+T_s] の間、自軌道カプセルに入射する殻粒子と遭遇する。
  入射は (x₀,v) 空間の Poisson 制限だから、
  「速度が錐 C_± = {w: ∠(w, ±e₁) ≤ θ} に入り、かつ伝播成功し、かつ
  マーク後 t_{k+1} まで生存し、かつ t_{k+1} に B_{n±1} に居る」子の数は
  **Poisson(μ_±)、μ_± ≥ c(θ, 幾何)·e^{−T_g/T_s}·p·ρq πR² w₁ q T_s**
  (θ と ℓ, T_g の整合で c > 0 を確保。子のマーク時刻の揺れ ≤ τ+T_s は

- ゆえに P(子が B_{n±1} に生存到達) ≥ 1 − exp(−μ) =: 1 − ε、

*(3) 独立性の管理*:
- 同一セルの ± 両ボンドは**速度錐で標的クラスが排反**(1粒子の速度は1錐にのみ属す)。

  超臨界方向付きパーコレーション → サイト鎖が無限に続く ⇒ 生存。∎(スケッチ)

*(4) 厳密化で埋める箇所(審査役向けの自己申告)*:
