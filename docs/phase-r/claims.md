# Phase R 主張と証明(セッション1)

> 規約はチェックポイント §0(device と一致)。M(ρ, ν, R, p, τ, T_s)。
> deg = (4π/3)ρR³、λ = ρπR² E|v_rel|、m = p(deg + λT_s)。

## 定理 A(絶滅・第一モーメント)【状態: 証明あり(再マーク禁止版)/ 再マーク版は補題ギャップ1件】

**主張**: 再マーク禁止版(死亡した点は再マークされない)の M において、
m = p(deg + λT_s) < 1 ならば、マークされる点の総数の期待値は 1/(1−m) 以下で有限。
したがって a.s. 絶滅する(T_s<∞)。

**証明**:
種を原点の追加点とする(Palm)。マーク事象は親試行の木をなす。深さ k のマーク点は
「時間順序つき開路」(i_0=種, i_1, …, i_k)に対応する: 各ステップで
(a) 順序対コイン U ≤ p、(b) 時刻列 t_1 ≤ … ≤ t_k が存在して t_j ∈ T_{i_{j-1} i_j} かつ
t_j ≤ t_{j-1} + τ + L_{j-1}(L は iid Exp(T_s):親は自分のマーク t_{j-1}+τ から
寿命 L_{j-1} の間だけ試行できる)。これはマーク成立の必要条件(緩和)である。

鍵の補題(**カプセル体積・厳密**): 速度 w の点が、時刻区間 [s, s+L] に源(位置 x、速度 v)
の半径 R 球と接触窓を交わらせる初期位置の集合は、半径 R のカプセル
(球 + 掃引円筒)であり、その体積はちょうど V_R + πR²|v−w|L。
ゆえに源1つ・寿命 L あたりの「使用可能ペア」の期待数は
ρ E_L[V_R + πR² E_w|v−w| L] = deg + λ T_s (源の速度 v で平均すれば E|v_rel|)。

相異なる k 点組への multivariate Mecke 公式で、
E[#深さ k の開路] ≤ p^k ρ^k ∫∏(カプセル体積の連鎖) = m^k。
(各ステップの被積分変数 (x_j, v_j) は新しい点であり、条件付けはカプセル制約のみ。
時刻列の存在は各ステップ独立に上の体積で上から押さえられる。)
再マーク禁止ではマーク点は相異なるので E[総マーク数] ≤ Σ_k m^k = 1/(1−m) < ∞。
マーク数有限+寿命有限 ⇒ 生存集合はいつか空。∎

**ギャップ(再マーク許可版)**: 経路が同一点を(非連続に)再訪しうる。順序対は
一度しか試行しないため辺の再利用はないが、再訪点のステップは Mecke の新鮮積分に
ならない。予想: 疎領域では補正は O(ρR³) で閾値を動かさない。
**未解決タスク A-1**: 再マーク版の第一モーメント補正 or 別法(質量輸送?)。
数値: 装置に再マーク数のカウンタを追加して疎領域で頻度を実測する(装置拡張タスク)。

## 定理 B(静的極限の同定)【状態: 証明あり(短い)】

**主張**: ν = δ_0(全点静止)のとき、M の到達集合はボンド希釈 RGG G(ρ, R; p)
(Poisson 点、距離 ≤ R の対を独立に確率 p で開く)における種の連結成分と一致する。
特に生存(総マーク無限)⟺ 種の成分が無限 ⟺ G(ρ,R;p) がパーコレートし種がその成分に入る。
**T_s と τ は生存に無関係**。

**証明**: 静止では T_ij = [0,∞)(|x_ij| ≤ R のとき)または空。j がマークされた瞬間
m_j に近傍対は「窓内」なので a_ij = m_j で即時試行(死亡は m_j より後、試行は
撃ちっ放しなので寿命は介在しない)。帰納的に、マーク集合 = 開辺で種から到達可能な
集合、マーク時刻 = ホップ数 × τ。∎

**数値**(E2, ρR³=1.0, deg=4.19): 巨大クラスタ出現は p ≈ 0.50–0.55。
(平均場 1/deg=0.24 と素朴 2.7/deg=0.65 の間 — ボンド RGG の文献値/独立実装照合は
タスク B-1: 動力学なしの純グラフ・ユニオンファインドで独立照合する。)

## 補題 C(使用可能ペア数の速度単調性)【状態: 証明あり】

**主張**: ν → s·ν₀(速度の一様スケール)のとき、源1つあたりの使用可能ペア期待数
deg + λ(s)T_s は s に単調非減少。deg 項は s に依存しない(時空定常性)。

**証明**: λ(s) = ρπR² s·E|v_rel|₀ は s に線形。deg は配置の定常性のみによる。∎

**注意**: これは分枝平均の単調性であり、生存確率そのものの s 単調性(予想 C4)は
未証明。結合(coupling)の障害: s を上げると接触窓が短くなり、
「マーク前に始まった窓を後から使う」機会(β_ij ≥ m_i 条件)は失われうる。
ただし E3 の数値は劇的に単調(σ: 0→0.1→0.25 で生存率 0.12→0.75→1.00)。
**タスク C-1 の結果(2026-08-15)**: 反例探索を理論的急所2点で実施 —
(E4) 静的閾値近傍 p=0.55・T_s=1.5・τ=0.5: 単調(0.69→1.00)。
(E4b/E4c) 静的ぎりぎりパーコレーション ρR³=0.7・p=1・T_s=1・τ=1:
16実現で σ=0.03 に谷の兆候 → **64実現で棄却**(0.734→0.781→0.797→0.844→0.906、
きれいに単調)。**棄却済みの枝**: 「小σ臨界谷」仮説は装置により棄却。
C4 は数値的に強固 — 次の仕事は結合(coupling)による証明構成。

## 規約依存性の明示(層3の解釈に必須)

進入駆動・撃ちっ放し(交付文書 §1.1)だから運動が単調に効く見込み。
滞在時間要求型(伝播に接触継続 τ_hold が必要)なら高速側で非単調になるはず。
この対比自体を層3の定理の一部として定式化する(タスク D-1: 滞在時間型の
装置バリアントと閾値比較 — ただしスコープは交付文書の規約が主、対比は従)。
